# Gately v0.6.0 发布

2026 年 10 月 27 日

这一版让 frp 支持多实例，Web 服务新增按登录用户分流（[#29](https://github.com/wangwanjie/gately/issues/29)）、站点分组排序（[#28](https://github.com/wangwanjie/gately/issues/28)）与转发登录 Cookie（[#30](https://github.com/wangwanjie/gately/issues/30)），并修复子域名证书签发失败（[#27](https://github.com/wangwanjie/gately/issues/27)）。

[下载 v0.6.0](/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.0)

## frp 多实例

- 可以同时运行多个 frpc 实例（各连一台 frps）和多个 frps 实例（各监听自己的端口），每个实例是独立进程，有自己的配置文件与日志来源，可单独启停、重启、编辑和删除；
- 代理归属某个 frpc 实例，列表可按实例筛选；修改代理只重启配置有变化的实例；删除 frpc 实例时一并删除它的代理；
- 程序路径移到单独的「程序」卡片；
- 导入 ini / toml 配置时可以导入到已有实例或新建实例，Lucky 导入会带上全部 frpc / frps 实例；
- 旧版的单个 frpc / frps 设置在升级后自动迁移为名为 frpc / frps 的实例，令牌和代理保持不变。

详见 [组网与穿透](/docs/modules/tunnels)。

## Web 服务

- **按登录用户分流**：开启基本认证、网页认证或转发认证的反向代理站点，可以把指定用户转发到各自的后端，类似 nginx 的 `map $remote_user $backend`。用户可以是站点用户、共享用户、第三方登录的 `提供方:ID`，或转发认证返回的 `Remote-User`；未列出的用户和公开路径上未登录的访客使用站点后端。还可以用 `X-Remote-User` 这类请求头把用户名传给后端，访客自己发送的同名请求头（包括用下划线代替连字符的写法）总会被删除。
- **站点分组、排序与搜索**：站点可以设置分组，列表按监听显示可折叠的分组；「排序」模式下可以上下移动或拖动站点、整组移动，也可以调整监听顺序；页头搜索框按域名、名称、分组、后端和备注过滤。顺序只影响列表显示，与域名匹配无关。
- **转发 Gately 登录 Cookie**：反向代理站点的新选项。开启后，单点登录与站点会话 Cookie 会原样转发给后端，这样公网 Gately 只负责 WAF 和访问控制，由内网 Gately 负责网页认证与单点登录。该选项不能与本站点的认证同时开启。

详见 [Web 服务](/docs/modules/web)。

## 证书

主域名留空时，DNS-01 验证会先用 SOA 查询验证记录所在的权威区域。子域名单独托管在另一家 DNS 服务商（如 web.example.com 与 example.com 分开托管）和多级后缀都能正确识别。查询失败、或查到的区域比可注册域名还短（例如本地 DNS 覆盖了上层域名）时，按域名推断主域名，原因记入日志。每张证书设置的 DNS 服务器只用于这张证书。

## 显示已保存的密码

被脱敏的密码、令牌和密钥旁边有眼睛按钮，点击后从新的 `.../secrets` 接口取回明文：

- 需要写权限，只读账号和只读 API 令牌返回 403，每次查看都记入审计日志；
- Web 终端的连接与认证预设密码和打开终端一样，需要先通过终端的二次验证；
- 用 bcrypt 保存的网页用户密码、OIDC 客户端密钥和私钥不会返回；
- 开启两步验证的共享用户可以重新查看二维码；
- `gately mcp` 默认的只读模式不提供这类接口，加 `--write` 才会提供。

## 升级提示

- 升级方式：Linux 二进制在「关于」页直接升级；Docker 拉取新镜像后重建容器；飞牛在应用中心安装新版 `.fpk`；OpenWrt 安装新版 `.ipk` / `.apk`。
- 配置格式向后兼容，可以直接升级。frp 旧配置会在首次启动时迁移为实例，旧版生成的 `frp/frpc.toml`、`frp/frps.toml` 会被删除。
- 接口 `/api/frp/client` 与 `/api/frp/server` 已移除，改为 `/api/frp/clients`、`/api/frp/servers` 与 `/api/frp/settings`。用脚本调用旧接口的需要相应修改。
- Docker 镜像仓库密码的脱敏占位符改为与其他模块一致的 8 个星号，旧的 6 个星号仍能识别。
