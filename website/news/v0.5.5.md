# Gately v0.5.5 发布

2026 年 10 月 21 日

这一版围绕“从 nginx 搬过来、搬过来之后少操心”：现有的 nginx 站点可以直接导入，证书续期后自动送到其他主机和容器，网盘与 WebDAV 站点也能挂 WAF，IP 访问控制可以引用定时更新的省市 IP 列表，网络自检能提前发现缺证书的站点和 frp 冲突。

[下载 v0.5.5](/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.5)

## 导入 nginx 配置

「Web 服务」页新增「导入 nginx」。在 nginx 所在主机执行 `nginx -T`，把完整输出粘贴进来即可，include 的文件会像 nginx 一样展开。

- 导入前先预览：按监听端口列出每个站点的类型、后端或目录、来源文件与行号，以及使用了变量、正则 location、缺少证书等需要注意的地方；
- 能转换反向代理（含 upstream 的权重、备用与负载均衡策略）、静态目录、跳转、固定内容、响应头与请求头、压缩、`allow` / `deny`，以及 location 级的分路径后端、访问控制与跳转；
- `auth_request` 转换为转发认证，Authelia 的常见写法（`set` 变量、`error_page 401` 登录跳转）可以直接转换，只在部分 location 启用时转换为“只对指定路径认证”；`auth_basic` 转换为使用共享用户的基本认证，导入后不会出现没有保护的站点；
- 相同端口的站点合并到已有监听，已存在的域名会跳过，可以重复导入；默认导入为停用状态，适合与 nginx 并行逐个核对。

这个功能用一份真实的生产配置（77 个站点、Authelia、upstream）验证过，转换结果与手工迁移一致。详见 [Web 服务 · 导入 nginx 配置](/docs/modules/web#import-nginx)。

## 证书自动部署

证书的编辑框新增「自动部署」，签发、续期或更新后自动执行：

- **上传到 SSH 主机**：选择 Web 终端中已有的 SSH 连接，证书写入远程目录后执行命令，例如 `systemctl reload nginx`，命令中可用 `$certName`、`$certDir`、`$certFile`、`$keyFile`；文件先写临时文件再替换，私钥权限为 0600；
- **重启本机容器**：证书变化后依次重启所选的 Docker 容器。

自动部署不会信任未知主机，SSH 连接需要先在 Web 终端中连接一次。失败时每小时重试，并发出新的「证书：部署失败」通知；证书卡片上的「立即部署」可以马上执行并显示每个目标的结果。详见 [SSL 证书](/docs/modules/ssl)。

## WAF：大文件上传与 WebDAV

- **请求体检查上限**可调（默认 12.5 MB，最大 1024 MB），超过上限时可以拒绝，也可以只检查前面部分、其余原样转发；
- **跳过请求体的路径**：上传接口不检查请求体，请求头、URL 与参数照常检查；
- **兼容 WebDAV 与上传**：放行 PUT、PROPFIND、MKCOL、MOVE、COPY、LOCK 等方法与 `Lock-Token`、`If`、`Content-Range` 请求头，不再限制上传的内容类型，网盘、WebDAV、文件管理站点挂上 WAF 也能正常使用，注入、路径穿越等攻击照常拦截；
- 所有实例放行 curl、rclone 上传大文件时带的 `Expect: 100-continue`，之前 OWASP CRS 4 会拦截这类上传。

详见 [WAF 防火墙](/docs/modules/waf)。

## 订阅 IP 列表

在「Web 服务 → 全局设置」按地址订阅 IP 列表并定时刷新，例如 [metowolf/iplist](https://github.com/metowolf/iplist) 的省市 IP 段。站点与路径规则的白名单、黑名单可以引用多个列表，与手填的 IP 段一起判断；下载内容缓存在本地，重启后无需联网；内容无法识别时保留上次的列表。详见 [Web 服务 · 订阅 IP 列表](/docs/modules/web)。

## 网络自检新增两项

- **HTTPS 站点证书**：列出没有匹配证书的域名，这些域名会在 TLS 握手时失败；
- **frp 冲突**：列出 frpc 中重名的代理，以及 frps 报告的代理名、域名或远程端口冲突。多台设备复制了同一份 frpc 配置时，后连上的设备注册失败，对应的网站会超时。

## 其他改进

- 在线升级支持 `v0.5.4.1` 这样的四段版本号；版本号无法比较时（如开发版）会明确提示，不再显示“已是最新”。
- 证书部署、nginx 导入预览等接口返回的说明文字按界面语言显示。

## 升级提示

- 从 v0.5.4 起，Linux 二进制部署可以在「关于」页直接升级到 v0.5.5；Docker 拉取新镜像后重建容器；飞牛在应用中心安装新版 `.fpk`；OpenWrt 安装新版 `.ipk` / `.apk`。
- 已经挂了 WAF 的网盘、WebDAV 站点，升级后在对应 WAF 实例中开启「兼容 WebDAV 与上传」即可正常上传。
