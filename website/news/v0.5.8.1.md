# Gately v0.5.8.1 发布

2026 年 10 月 26 日

这是 v0.5.8 系列的功能更新，来自 [issue #18](https://github.com/wangwanjie/gately/issues/18)、[#19](https://github.com/wangwanjie/gately/issues/19)、[#20](https://github.com/wangwanjie/gately/issues/20)、[#22](https://github.com/wangwanjie/gately/issues/22) 的建议。

[下载 v0.5.8.1](/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.8.1)

## 文件服务共享用户

WebDAV、FTP、SMB 可以共用一份「共享用户」，只需维护一次密码与目录。三个服务页面都有「共享用户」卡片，在任一页面修改都会同时生效；每个服务用「本服务启用」开关决定是否接受共享用户，原有的本地用户照常使用，同名时以本地用户为准。只用共享用户也可以启用服务。修改后 WebDAV 下一个请求即按新设置校验，FTP 会断开已登录的会话，SMB 在账号变化时重新加载。详见 [文件服务](/docs/modules/tools#shared-users)。

## 断开连接站点与访问日志

站点类型新增「断开连接」，不返回任何内容直接断开，相当于 nginx 的 `return 444`。适合设为默认站点，让扫描未知域名的请求得不到任何响应，访问日志记为 444。导入 nginx 配置时 `return 444` 会转为这一类型。

Web 服务的访问日志末尾按 nginx combined 格式附上 Referer 与 User-Agent，便于区分同一出口 IP 后面的不同设备。详见 [Web 服务](/docs/modules/web)。

## frps 监听地址

frps 可以分别设置 frpc 连接端口的监听地址与代理端口（HTTP、HTTPS 及 tcp/udp 代理的远程端口）的监听地址，留空为所有地址。例如把 frps 只监听在 127.0.0.1，由 Gately 的站点以 websocket 或 wss 转发给它。详见 [内网穿透](/docs/modules/tunnels)。

## 复制按钮与两步验证

通过 HTTP 访问管理界面时，浏览器不提供剪贴板接口，复制按钮现在会自动改用兼容方式；仍失败时会选中文本并提示手动复制。两步验证的输入框可以被 Bitwarden 等密码管理器识别并自动填入验证码。

## 升级提示

- 修改共享用户需要 API 令牌同时具备 `webdav:write`、`ftp:write` 与 `smb:write`；只靠共享用户启用的服务不能把共享用户删光。
- 「断开连接」站点不经过认证、访问控制与 WAF，站点的其他设置不生效。
- 访问日志中过长的地址、Referer 与 User-Agent 会被截断。
