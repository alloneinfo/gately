# Gately v0.5.3 发布

2026 年 10 月 21 日

这一版的主角是飞牛 fnOS。Gately 现在可以作为飞牛原生应用安装：从飞牛桌面图标打开，走飞牛自己的访问入口，飞牛管理员不用再单独登录一次。另外，用不到的功能模块可以整个关掉。

[下载 v0.5.3](/download#fnos) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.3)

## 飞牛 fnOS 原生应用

每个版本附带飞牛离线安装包 `gately_0.5.3_fnos_x86.fpk`（Intel / AMD）与 `gately_0.5.3_fnos_arm.fpk`（ARM），在飞牛「应用中心 → 手动安装」中选择文件即可。

- **支持飞牛统一网关**：点击桌面图标，管理界面在 `/app/gately/` 下打开，与飞牛共用同一个访问入口。局域网地址、远程访问飞牛的域名都能直接用，不需要再开放或映射 16680 端口。经网关访问时由飞牛负责访问控制，只有飞牛管理员能打开。
- **支持飞牛管理员登录态直接登录**：在「设置 → 访问控制」开启「飞牛登录态自动登录」后，已登录飞牛的管理员点开图标就进入 Gately，不用再输入密码与两步验证码；普通飞牛用户仍需登录。主动退出后，登录页会显示「使用飞牛账号 &lt;用户名&gt; 登录」按钮，不会静默重新登录。该开关默认关闭。
- **完整能力**：应用以 root 运行，可以监听 80/443、管理 Docker、使用 Web 终端；配置在卸载时默认保留，升级时安装新版 `.fpk` 即可。

安装与注意事项见 [安装部署 · 飞牛 fnOS 原生应用](/docs/guide/install#fnos)。

## 功能模块开关

「设置 → 功能模块」可以关闭整个模块。关闭的模块只加载配置，不启动服务、不提供管理接口（接口返回 403），并从界面中隐藏；配置会保留，重新开启后恢复。被其他模块依赖的模块不能关闭，修改后重启生效。只用其中几项功能的人，可以借此减少监听的服务与可调用的接口。

## 其他改进

- 管理界面每种语言的文案合并为一个文件，首次打开的请求数从约 170 个降到约 75 个；懒加载的页面或样式加载失败时自动刷新一次。
- 接口文档补充了功能模块开关与飞牛相关设置字段的说明。

## 升级提示

- Docker：拉取新镜像后重建容器；二进制：替换可执行文件后重启。
- 飞牛原生应用与 Docker 镜像都使用 16680 端口。从 Docker 版换到原生应用前，请先停止 `gately` 容器，并把配置目录复制到应用的 `var/config`。
