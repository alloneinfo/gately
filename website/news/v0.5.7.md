# Gately v0.5.7 发布

2026 年 10 月 24 日

这一版给存储挂载加上 SMB 共享（[#14](https://github.com/wangwanjie/gately/issues/14)），重做了主题，并让管理界面在弱网和多标签页下更省流量、更轻快。

[下载 v0.5.7](/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.7) · [文件服务文档](/docs/modules/tools)

## SMB 共享挂载

- 挂载地址写成 `smb://主机[:端口]/共享名[/子目录]`，可连接 Windows 共享、NAS 与 Samba，使用 SMB2/3；
- 支持用户名、密码与可选的域或工作组，用户名留空时以来宾身份连接；
- 与本地目录、WebDAV 挂载一样可以在线管理文件，也可以作为定时备份的目的地；
- 首次使用时才建立连接，服务端断开后在下一次操作时自动重连；用户名密码错误、共享不存在时给出明确提示。

## 菜单改名

侧边栏「网络存储」改为「文件服务」，其中「存储管理」改为「存储挂载」（Gately 连接本地目录、远程 WebDAV 或 SMB 共享），「WebDAV」改为「WebDAV 服务」（Gately 把本地目录共享出去，与「FTP 服务」并列）。概览、导入报告、API 令牌权限与接口文档中的模块名称同步更新。

## 主题

- 15 个色系分为 Gately 原创（翠绿、海洋、清新、樱花、暮光、午夜、朋克）和经典配色（GitHub、Nord、Dracula、Catppuccin、Tokyo Night、Gruvbox、Rosé Pine、Solarized），每个色系都有亮色与暗色，跟随系统对所有色系都可用；
- 任一色系都可以换成 10 种预设主色之一或用取色器自选，Logo 与登录页渐变随之变化；圆角可选直角、跟随色系或圆润；
- 主题面板支持悬停预览，切换时有圆形展开动画；
- Web 终端新增「跟随界面主题」配色并作为默认，Docker 容器终端也使用同一配色偏好；
- 所有色系的文字、次要文字、主色与按钮都通过了对比度检查。

旧版本选择的主题会在首次打开时自动迁移，原来的「暗黑」对应翠绿的暗色版本。

## 更快、更省流量

- 管理界面的接口响应与首页使用 br / gzip 压缩，脚本和样式在构建时预压缩：250 KB 的接口描述传输约 15 KB，850 KB 的主脚本约 270 KB；
- 程序缩小约 15%，Linux amd64 约 32 MB；
- 标签页切到后台时，15 个页面与面板的定时刷新自动暂停，切回时立即刷新一次；上一次请求未返回时跳过本轮；
- 日志卡片首次只拉取最近 200 条，更早的日志点「加载更早的日志」按页补充；日志接口新增 `limit` 与 `before` 参数；
- DDNS 页面一次往返加载完成。

## 修复

- 开启压缩的 Web 服务站点：经 HTTP 访问（浏览器只声明 gzip）时，反代上游已经 gzip 的响应被再压一次，浏览器收到乱码；
- 入侵防护：保存设置或模块重启后，丢弃包数、诱饵端口与扫描检测的命中计数归零；
- 语言菜单、主题面板、用户菜单打开时，滚轮和触摸仍会滚动下方页面；
- 在线升级失败后立即重试偶尔提示「升级进行中」。

## 升级提示

- 升级方式：Linux 二进制在「关于」页直接升级；Docker 拉取新镜像后重建容器；飞牛在应用中心安装新版 `.fpk`；OpenWrt 安装新版 `.ipk` / `.apk`。
- 配置格式没有变化，可以直接升级；主题选择保存在浏览器本地，升级后各浏览器第一次打开时自动迁移。
- 菜单改名不影响已有配置与 API 路径，`/api/storage/*` 与 `/api/webdav/*` 保持不变。
