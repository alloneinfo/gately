# Gately v0.5.4 发布

2026 年 10 月 21 日

这一版解决“怎么装、怎么升级”。systemd、PVE LXC 容器、手动部署的 OpenWrt 等 Linux 二进制部署，现在可以在管理界面里直接升级；OpenWrt 与 iStoreOS 用户可以用系统自带的包管理器安装 Gately。

[下载 v0.5.4](/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.4)

## 在线升级

在「关于」页点击「检查更新」，会弹出新版本的版本号、发布日期与更新内容，点击「立即升级」后 Gately 依次：

1. 从 GitHub 下载与本机平台对应的发布包；
2. 对照同一版本的 `checksums.txt` 校验 SHA-256；
3. 试运行新程序，确认能在本机执行；
4. 替换可执行文件并原地重启，旧版本保留为同目录下的 `gately.old`，便于回退。

弹窗里实时显示当前步骤、下载进度与速度，替换程序之前可以随时取消；刷新页面后会接着显示仍在进行的升级，失败时给出原因并可重试。

- **PVE LXC 容器**：用 OCI 镜像创建的 LXC 容器同样可以在线升级，不用再删除容器重建；
- **更新代理**：访问 GitHub 不稳定时，可以在「关于」页或「设置 → 网络与运行」设置 http、https 或 socks5 代理，检查更新与下载都会经过它；
- **离线升级与回退**：「上传升级包」接受发布页的 tar.gz 或解压后的程序，不限版本高低，也能用来回退；
- **只由管理员手动触发**：Gately 不会自动下载或安装任何版本。Docker、飞牛 fnOS 与 OpenWrt 安装包会提示各自的升级方式。

详见 [安装部署 · 在线升级](/docs/guide/install#online-upgrade)。

## OpenWrt 安装包

每个版本附带 OpenWrt 安装包，架构有 amd64 / arm64 / arm / mipsle / mips / riscv64：

- OpenWrt 24.10 及以前（含 iStoreOS）：`opkg install ./gately_v0.5.4_openwrt_<架构>.ipk`
- OpenWrt 25.12 起：`apk add --allow-untrusted ./gately_v0.5.4_openwrt_<架构>.apk`

安装后自动启用开机自启并启动，管理界面在 `http://<路由器地址>:16680`。配置保存在 `/etc/gately`，升级、卸载与刷写固件时都会保留；升级时安装新版安装包即可。安装前会核对设备架构，按 `/etc/openwrt_release` 中的 `DISTRIB_ARCH` 选包。程序约 35 MB，适合 x86 软路由、ARM64 盒子等存储较大的设备。

详见 [安装部署 · OpenWrt](/docs/guide/install#openwrt)。

## 问题修复

- 通过 Gately 自身转发访问管理界面时，保存设置不再断开连接：编辑端口转发规则时，只要监听端口、协议、模式与限制不变，就原地更新目标与 SNI 分流并保留现有连接；保存端口转发或 Web 服务设置也不再重启全部监听。
- WAF 不再把 `credentials`、`forwardAuth` 这类 JSON 字段名误判为系统文件访问，保存 DDNS 任务或添加 Web 服务监听时不再返回 403。
- 域名、IP 列表、请求头、STUN 服务器等列表输入框不再吞掉回车、逗号与空格。
- mips / mipsle 程序改为软浮点编译，可以在没有硬件浮点单元的路由器上运行。
- 版本比较改为语义化版本，较新的构建不会再被提示“升级”到旧版本。

## 升级提示

- 在线升级从 v0.5.4 开始提供，这一次仍需手动升级：二进制替换后重启，Docker 拉取新镜像后重建容器，飞牛在应用中心安装新版 `.fpk`。之后的版本就可以在「关于」页直接升级。
- 之前手动部署在 OpenWrt 上的，可以直接安装 `.ipk` / `.apk` 覆盖，`/etc/gately` 中的配置会继续使用。
