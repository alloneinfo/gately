# Gately v0.5.9 发布

2026 年 10 月 26 日

这一版新增托管 File Browser（[#23](https://github.com/wangwanjie/gately/issues/23)）和 IP 地址证书（[#24](https://github.com/wangwanjie/gately/issues/24)），并让托管的外部程序都可以在线安装和回滚。

[下载 v0.5.9](/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.9)

## File Browser

「文件服务」新增「File Browser」，托管网页文件管理器 [FileBrowser Quantum](https://github.com/gtsteffaniak/filebrowser)。原版 filebrowser/filebrowser 已在 2026 年归档、不再修复安全问题，因此选用仍在维护的 Quantum 分支。

- 每个实例可设置监听地址与端口、访问路径（便于按路径反向代理）、一个或多个共享目录（可单独设为只读）、界面语言与登录有效期；
- 登录方式可选账号密码、信任反向代理传入的用户名请求头（配合 Web 服务的网页认证），或不登录（会有醒目提示）；
- 管理员密码通过环境变量传给 File Browser，每次启动同步，不写入任何文件；
- 共享目录不存在时拒绝启动，删除实例时一并删除其数据目录（用户、分享链接、缓存），共享目录里的文件不受影响。

详见 [文件服务](/docs/modules/tools)。

## IP 地址证书与短期证书

ACME 证书新增「证书配置」，可选 CA 默认、Let's Encrypt 的短期证书（约 6 天）或 CA 支持的其他配置名。

- 域名列表中可以直接填写公网 IPv4、IPv6 地址，签发 IP 地址证书；IP 证书需使用 HTTP-01 验证，Let's Encrypt 需选短期证书，编辑器会提示并可一键设置；
- 预置 CA 只为公网地址签发，内网、回环与 100.64.0.0/10 地址会被拒绝；自建 CA（如 step-ca）不受这些限制，仍需 HTTP-01 验证；
- 不带 SNI 的 TLS 连接（按 IP 访问）自动使用与本机地址匹配的 IP 证书；
- 短期证书在到期前按「短期证书提前小时数」续签（默认 24 小时，最多 80 小时），失败后每小时重试；证书卡片显示「短期」标签与剩余小时数。

详见 [SSL 证书](/docs/modules/ssl)。

## 托管程序在线安装

frp、cloudflared、Tailscale 与 File Browser 的页面都有「在线安装」卡片：

- 安装最新正式版或指定版本（也可降级），下载后校验 SHA-256、确认能在本机运行后才替换，并自动重启使用该程序的进程；
- 每个程序可单独设置下载代理（http、https、socks5），留空沿用全局「更新代理」；
- 替换下来的旧版本保存在配置目录的 `bin/.versions/` 下，最多 3 个，可一键回滚或删除；
- 「卸载」删除安装的程序与全部旧版本，模块配置保留；
- 页头的「恢复默认配置」停止进程并把模块配置恢复为默认，旧配置保存在配置历史中；
- Tailscale 只在 Linux 上提供在线安装（官方没有 macOS、Windows 的静态包）。

程序查找顺序改为：页面中填写的路径 → 配置目录下的 `bin/` → `PATH`，在线安装的程序优先生效。详见 [组网与穿透](/docs/modules/tunnels)。

## 文件服务共享用户

WebDAV、FTP、SMB 的共享用户改到「文件服务 → 文件共享用户」独立页面编辑，页面列出每个服务是否启用、是否允许共享用户，以及被同名本地用户覆盖的用户。各服务页面只保留「允许共享用户登录」开关。新增接口 `GET/PUT /api/fileusers` 与令牌权限 `fileusers:read`、`fileusers:write`，原有的 `/api/<服务>/shared-users` 继续可用。

## 升级提示

- 升级方式：Linux 二进制在「关于」页直接升级；Docker 拉取新镜像后重建容器；飞牛在应用中心安装新版 `.fpk`；OpenWrt 安装新版 `.ipk` / `.apk`。
- 配置格式向后兼容，可以直接升级，已有证书不会因升级重新签发。
- 程序查找顺序变化后，若配置目录的 `bin/` 下已有同名程序，会优先使用它而不是 `PATH` 中的程序。
- 已在「功能模块」中关闭的文件服务不再阻止修改共享用户。
