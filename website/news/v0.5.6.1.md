# Gately v0.5.6.1 发布

2026 年 10 月 22 日

这是 v0.5.6 的修复版本，只涉及 Docker 镜像，建议 Docker 用户升级。

[下载 v0.5.6.1](/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.6.1)

## 修复宿主机 nft 崩溃

v0.5.6 的 Docker 镜像内置 nftables 1.1.5。nftables 从 1.1.2 起会在集合上写入旧版不认识的元数据，宿主机上 1.1.1 之前的 nft（如 Debian 12、飞牛 fnOS 自带的 1.0.6）执行 `nft list ruleset` 时会因此崩溃；Gately 自身读写规则不受影响。

这一版把镜像中的 nftables 固定为 1.1.1。升级后 Gately 启动时会重建 `inet gately` 表，宿主机的 nft 即可恢复正常。飞牛安装包、OpenWrt 安装包与二进制部署使用的是系统自带的 nft，不受影响。

## 升级提示

- Docker 拉取新镜像后重建容器即可。其余部署方式与 v0.5.6 相同，可以不升级。
