# Gately v0.5.7 リリース

2026年10月24日

このリリースではストレージマウントに SMB 共有を追加し（[#14](https://github.com/wangwanjie/gately/issues/14)）、テーマを作り直し、低速回線やタブを多く開いた状態でも管理画面が軽く動くようにしました。

[v0.5.7 をダウンロード](/ja/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.7) · [ファイルサービスのドキュメント](/ja/docs/modules/tools)

## SMB 共有のマウント

- マウント先のアドレスを `smb://ホスト[:ポート]/共有名[/サブディレクトリ]` と書くと、Windows 共有、NAS、Samba サーバーに SMB2/3 で接続します；
- ユーザー名、パスワード、任意のドメインまたはワークグループを指定できます。ユーザー名が空欄の場合はゲストとして接続します；
- ローカルディレクトリや WebDAV のマウントと同じく、オンラインのファイル管理と定期バックアップの保存先に使えます；
- 接続は初めて使うときに確立し、サーバー側で切断された場合は次の操作で再接続します。認証情報の誤りや共有が存在しない場合はわかりやすいエラーを表示します。

## メニュー名の変更

サイドバーの「ネットワークストレージ」は「ファイルサービス」になりました。「ストレージ管理」は「ストレージマウント」（Gately がローカルディレクトリ、リモートの WebDAV、SMB 共有に接続する機能）に、「WebDAV」は「WebDAV サービス」（Gately がローカルディレクトリを共有する機能で、「FTP サービス」と並びます）に変わります。概要、インポートレポート、API トークンの権限、API ドキュメントのモジュール名も新しい名前に合わせました。

## テーマ

- 15 のパレットを 2 つのグループに分けました。Gately オリジナル（エメラルド、オーシャン、フレッシュ、サクラ、サンセット、ミッドナイト、パンク）と定番パレット（GitHub、Nord、Dracula、Catppuccin、Tokyo Night、Gruvbox、Rosé Pine、Solarized）です。どのパレットにもライトとダークがあるため、「システム」に合わせる設定がすべてのパレットで使えます；
- どのパレットでも 10 種類のプリセットのアクセントから選ぶか、カラーピッカーで色を選べます。ロゴとログイン画面のグラデーションもそれに合わせて変わります。角丸はシャープ、パレット、丸めから選べます；
- テーマパネルはホバーでプレビューでき、切り替え時は円形に広がるアニメーションで表示されます；
- Web ターミナルに「UI テーマに合わせる」配色を追加して既定にしました。Docker のコンテナターミナルも同じ設定を使います；
- すべてのパレットで、文字、補助テキスト、アクセント、ボタンがコントラストのチェックに合格しています。

以前のバージョンで選んだテーマは、初めてページを開いたときに自動で移行されます。従来の「ダーク」はエメラルドのダーク版になります。

## より速く、より軽く

- 管理画面の API レスポンスとトップページを br または gzip で送信し、スクリプトとスタイルはビルド時に事前圧縮します。250 KB の API 説明は約 15 KB、850 KB のメインスクリプトは約 270 KB で転送されます；
- プログラムは約 15% 小さくなり、Linux amd64 版で約 32 MB です；
- タブがバックグラウンドにある間は 15 のページとパネルの定期更新を一時停止し、再び表示されたときにすぐ更新します。前回のリクエストが終わっていない場合はその回をスキップします；
- ログカードは最初に最新の 200 件だけを取得し、古いログは「以前のログを読み込む」でページ単位に追加します。ログ API に `limit` と `before` パラメーターを追加しました；
- ダイナミック DNS のページは 1 回の往復で読み込みが完了します。

## 修正

- 圧縮を有効にした Web サービスのサイト：プレーンな HTTP で接続し、ブラウザーが gzip だけを受け付ける場合に、上流で gzip 済みのレスポンスが再度圧縮され、ブラウザーで文字化けしていました；
- 侵入防御：設定の保存やモジュールの再起動後に、破棄したパケット数、おとりポート、スキャン検出のヒット数が 0 に戻っていました；
- 言語メニュー、テーマパネル、ユーザーメニューを開いているとき、マウスホイールやタッチで下のページがスクロールしていました；
- オンラインアップグレードの失敗直後に再試行すると、まれに「アップグレード中です。しばらくお待ちください」と表示されていました。

## アップグレードについて

- アップグレード方法：Linux バイナリ版は「バージョン情報」ページから直接アップグレードできます。Docker は新しいイメージを取得してコンテナを再作成、fnOS はアプリセンターで新しい `.fpk` を、OpenWrt は新しい `.ipk` / `.apk` をインストールします。
- 設定ファイルの形式は変わっていないので、そのままアップグレードできます。テーマの選択はブラウザーに保存されており、各ブラウザーで初めてページを開いたときに移行されます。
- メニュー名の変更は既存の設定と API パスに影響しません。`/api/storage/*` と `/api/webdav/*` はそのままです。
