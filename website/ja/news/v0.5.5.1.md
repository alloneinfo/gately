# Gately v0.5.5.1 リリース

2026年10月21日

このリリースは [issue #8](https://github.com/wangwanjie/gately/issues/8) に対応します。これまで各モジュールの実行ログはメモリ上にのみ保持され、コンテナの再起動やアップグレードで消えていました。

[v0.5.5.1 をダウンロード](/ja/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.5.1)

## 実行ログの永続化

- システムログと各モジュールのログは、既定で設定ディレクトリの `logs/` に出力元ごとの JSON Lines ファイルとして書き込まれ、再起動やアップグレード後も「システムログ」と各モジュールのページで以前のログを確認できます
- 新しいログは最大 1 秒遅れてまとめて書き込まれ、アイドル時には書き込みが発生しません。1 ファイルの上限は既定で 2 MB で、上限に達するとローテーションして 1 世代分を残します
- 「設定 → ネットワークと実行 → 実行パラメーター」に「ログを永続化」スイッチと「ログファイル上限」を追加しました。変更はすぐに反映され、オフにすると従来どおりメモリ上にのみ保持します
- 画面でモジュールのログを消去すると対応するファイルも削除されます。設定のバックアップにログは含まれません

操作監査ログは以前から `audit.log` に保存されており、変更はありません。詳しくは [設定と実行パラメーター · 実行ログ](/ja/docs/guide/configuration#実行ログ) を参照してください。

## アップグレードについて

- v0.5.5 から：Linux バイナリ版は「バージョン情報」ページから直接アップグレードできます。Docker は新しいイメージを取得してコンテナを再作成、fnOS はアプリセンターで新しい `.fpk` を、OpenWrt は新しい `.ipk` / `.apk` をインストールします。
- v0.5.4 以前の「更新を確認」は 3 桁のバージョン番号しか認識しないため、v0.5.5.1 は表示されません。「バージョン情報」ページの「アップグレードパッケージをアップロード」で Release から該当プラットフォームの `.tar.gz` をインストールするか、先に v0.5.5 へアップグレードしてください。
- Docker の場合、ログはマウントした設定ディレクトリ内（例：`./gately-data/logs/`）にあります。
