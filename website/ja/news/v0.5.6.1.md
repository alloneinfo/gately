# Gately v0.5.6.1 リリース

2026年10月22日

v0.5.6 の修正リリースで、Docker イメージのみが対象です。Docker をお使いの方はアップグレードしてください。

[v0.5.6.1 をダウンロード](/ja/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.6.1)

## ホストの nft のクラッシュを修正

v0.5.6 の Docker イメージには nftables 1.1.5 が含まれていました。nftables は 1.1.2 以降、古いバージョンが理解できないメタデータをセットに書き込むため、ホストの 1.1.1 より古い nft（Debian 12 や fnOS の 1.0.6 など）で `nft list ruleset` を実行するとクラッシュします。Gately 自身のルールの読み書きには影響しません。

このリリースではイメージの nftables を 1.1.1 に固定しました。アップグレード後、Gately は起動時に `inet gately` テーブルを作り直し、ホストの nft も正常に戻ります。fnOS パッケージ、OpenWrt パッケージ、バイナリ版はシステムの nft を使うため影響を受けません。

## アップグレードについて

- Docker は新しいイメージを取得してコンテナを再作成してください。その他のデプロイ方法は v0.5.6 と同じで、アップグレードは不要です。
