# 更新履歴

主要なバージョンのリリースのお知らせを以下に掲載します。各バージョンの変更点の全体とダウンロードファイルは [GitHub Releases](https://github.com/wangwanjie/gately/releases) を参照してください。

## [v0.5.5](/ja/news/v0.5.5)

2026年10月21日 · nginx 設定のインポート、他のホストやコンテナへの証明書の自動デプロイ、WAF の大容量アップロードと WebDAV への対応、購読 IP リストを追加し、自己診断に証明書の有無と frp の競合の確認が加わりました。

## [v0.5.4](/ja/news/v0.5.4)

2026年10月21日 · Linux バイナリ導入でオンラインアップグレードに対応し、PVE の LXC コンテナを作り直す必要がなくなりました。OpenWrt パッケージ（.ipk / .apk）を追加しました。

## [v0.5.3](/ja/news/v0.5.3)

2026年10月21日 · fnOS ネイティブアプリ：fnOS 統一ゲートウェイに対応し、fnOS 管理者は fnOS のログイン状態でそのままログインできます。機能モジュールを個別に有効化・無効化できるようになりました。

## [v0.5.2](/ja/news/v0.5.2)

2026年10月20日 · SNI 振り分けで複数のサービスが 443 番ポートを共用でき、Web サービスで nginx を置き換えられます。共有ユーザーは TOTP とシングルサインオンに対応しました。haproxy + nginx との性能比較も掲載しています。

## [v0.5.0](/ja/news/v0.5.0)

2026年10月19日 · 監査ログ、設定履歴とロールバック、Passkey、読み取り専用アカウント、ACME HTTP-01、HTTP/3、PROXY プロトコル、全体の Prometheus メトリクス、ネットワーク自己診断、署名付きリリース。
