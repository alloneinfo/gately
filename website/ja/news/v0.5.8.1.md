## ファイルサービスの共有ユーザー

WebDAV、FTP、SMB で 1 つの「共有ユーザー」一覧を共用でき、パスワードとディレクトリを一度管理するだけで済みます。3 つのサービス画面すべてに「共有ユーザー」カードがあり、どの画面で変更しても同時に反映されます。共有ユーザーを受け付けるかはサービスごとのスイッチで決め、既存のローカルユーザーはそのまま使え、同名の場合はローカルユーザーが優先されます。共有ユーザーだけでサービスを有効にすることもできます。変更後、WebDAV は次のリクエストから新しい設定で認証し、FTP はログイン中のセッションを切断し、SMB はアカウントが変わったときに再読み込みします。詳しくは [ファイルサービス](/ja/docs/modules/tools#shared-users) を参照してください。

## 接続を切断するサイトとアクセスログ

サイトの種類に「接続を切断」を追加しました。何も返さずに接続を切断し、nginx の `return 444` に相当します。デフォルトサイトに設定すると、未知のドメインをスキャンするリクエストに一切応答せず、アクセスログには 444 として記録されます。nginx 設定のインポートでは `return 444` がこの種類に変換されます。

Web サービスのアクセスログの末尾に、nginx combined 形式で Referer と User-Agent を記録するようになり、同じグローバル IP の背後にある端末を見分けられます。詳しくは [Web サービス](/ja/docs/modules/web) を参照してください。

## frps の待ち受けアドレス

frps は frpc の接続ポートと、プロキシポート（HTTP、HTTPS、tcp/udp プロキシのリモートポート）の待ち受けアドレスをそれぞれ指定できます。空欄はすべてのアドレスです。たとえば frps を 127.0.0.1 だけで待ち受け、Gately のサイトから websocket や wss で転送できます。詳しくは [トンネル](/ja/docs/modules/tunnels) を参照してください。

## コピーボタンと 2 段階認証

HTTP で管理画面を開くとブラウザがクリップボード API を提供しないため、コピーボタンは自動で互換方式に切り替わります。それでも失敗した場合はテキストを選択して手動でのコピーを案内します。2 段階認証の入力欄は Bitwarden などのパスワードマネージャーに認識され、コードを自動入力できます。

## アップグレード時の注意

- 共有ユーザーの変更には、API トークンに `webdav:write`、`ftp:write`、`smb:write` のすべてが必要です。共有ユーザーだけで有効にしているサービスでは、共有ユーザーをすべて削除できません。
- 「接続を切断」サイトは認証、アクセス制御、WAF を通らず、サイトのその他の設定は効きません。
- アクセスログの長すぎる URI、Referer、User-Agent は切り詰められます。
