# ダイナミック DNS（DDNS）

家庭用ブロードバンドの公開 IP は変化します。DDNS は IP が変わると DNS レコードを自動で更新し、ドメイン名が常に現在のアドレスを指すようにします。

## 対応プロバイダー

Alibaba Cloud、Cloudflare、Tencent Cloud、DNSPod、Huawei Cloud、GoDaddy、Porkbun、dynv6、DuckDNS、およびカスタムコールバック（未対応のプロバイダーや自前の API 用）。

## IP の取得方法

- **URL**：公開 IP の照会アドレスにリクエストします（任意のサービスに置き換えたり、自前で用意したりできます）。
- **NIC**：指定したネットワークインターフェースのアドレスを直接読み取ります。公開 IP を持つデバイスに向いています。
- **コマンド**：コマンドを実行してその出力を使います。特殊なネットワーク環境向けです。

IPv4 と IPv6 に対応しています。

## 通知

IP の変化や同期の失敗時に Webhook を呼び出せます。

## 利用のヒント

- DNS プロバイダーでは、レコード編集権限だけを持つサブアカウントのキーを作成して使い、メインアカウントのキーは使わないでください。
- タスクを作成したら「強制同期」を押して、レコードが更新されたことを確認します。
- 公開 IP の照会アドレスはプロジェクト側のサービスに依存しないため、タスクでいつでも変更できます。

## Lucky からの移行

DDNS タスクは `lucky_ddns.lkcf` からインポートでき、11 のプロバイダーに対応しています。Lucky 公式の IP 照会アドレスはインポート時に削除されます。詳しくは [移行ガイド](/ja/docs/guide/migration) を参照してください。
