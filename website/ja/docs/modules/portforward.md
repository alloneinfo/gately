# ポート転送

ローカルで待ち受けているポートを、別のデバイスやサービスへ転送します。

## 機能

- TCP と UDP
- IPv4 と IPv6。v4 と v6 の間で相互に転送できます
- ポート範囲と複数ポート
- 複数ターゲットとフェイルオーバー
- 接続数制限
- トラフィック統計と実行ログ

## 典型的な利用シーン

- NAS のサービスポートを共通の入口にまとめて公開する
- IPv6 と IPv4 の間で相互接続できるよう転送する
- 1 つのサービスに主系・待機系の 2 つのバックエンドを設定する

## デプロイのヒント

ポート転送はホストのポートを直接待ち受けるため、Docker でデプロイする場合は `--network host` を推奨します。

## Lucky からの移行

ルールは `lucky_portforward.lkcf` からインポートできます。TLS / ストリーム暗号化や速度制限などのオプションは未対応で、インポート時に通知されます。
