# SSL 証明書

証明書を自動で取得・更新し、[Web サービス](/ja/docs/modules/web) で使えるほか、他のソフトウェアへエクスポートすることもできます。

## 機能

- **ACME DNS-01** による自動発行・更新。[ダイナミック DNS](/ja/docs/modules/ddns) の DNS プロバイダーを再利用するため、80 / 443 ポートを開放する必要がありません
- ワイルドカード証明書と EAB（ZeroSSL など）
- 既存の証明書のアップロード、またはファイルからの読み込み
- ディレクトリへのマッピング：証明書が変わったら指定ディレクトリに書き込み、スクリプトを実行して、他のサービスのリロードを容易にします

## 証明書のマッピング

証明書を有効にすると、Gately は `.crt`、`.key`、`.pem`、`_issuerCertificate.crt` をマッピング先ディレクトリに書き込み、変更時のスクリプトを実行します。

## セキュリティ上の注意

秘密鍵は設定ディレクトリの `ssl.json` に保存されます。このファイルを厳重に管理し、バージョン管理に入れる場合はリポジトリがプライベートであることを確認してください。

## Lucky からの移行

発行済みの証明書はそのままインポートでき、有効期限が切れるまで再取得されません。ZeroSSL は Lucky の EAB 認証情報を引き継いで、新しい ACME アカウントを登録します。詳しくは [移行ガイド](/ja/docs/guide/migration) を参照してください。
