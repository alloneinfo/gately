# Lucky との比較

Gately は Lucky にインスパイアされ、主要な機能をオープンソースでカバーし、既存の設定もインポートできます。機能の幅広さやユーザーの蓄積では Lucky が先を行っており、Lucky がなければ Gately は生まれませんでした。ここに感謝を記します。

## 理念の違い

| 項目 | Gately | Lucky |
| --- | --- | --- |
| ソースコード | オープンソース（Apache-2.0） | クローズドソース |
| 設定ファイル | 平文の JSON、git で管理可能 | 独自形式（`.lkcf`） |
| 公式サービス | デフォルトではなし。外部へのアドレスはすべて変更・無効化可能 | オンライン更新、外部ログイン中継などの公式サービスを提供 |
| 外部ログイン | 自分の OAuth アプリを使用 | 公式の中継サービス経由 |
| アップグレード方法 | Docker / パッケージマネージャー | 内蔵のオンライン自動更新 |
| 機能の幅 | 主要なコア機能をカバー | より豊富（DLNA、ネットワークドライブのマウントなど） |

## 機能のカバー範囲

| 機能 | Gately |
| --- | --- |
| ダイナミック DNS | ✅ |
| STUN 穿孔 | ✅ |
| ポート転送 | ✅ |
| SSL 証明書 | ✅ |
| Web サービス（リバースプロキシ） | ✅ |
| WAF | ✅ |
| Tailscale / frp / cloudflared | ✅ |
| Docker 管理 | ✅ |
| Web ターミナル | ✅ |
| WebDAV / FTP / ストレージ管理 | ✅ |
| Wake-on-LAN / スケジュールタスク | ✅ |
| 通知センター / 設定バックアップ / ネットワーク診断 | ✅ |
| API トークン / OpenAPI / コマンドライン / MCP | ✅ |
| DLNA、ネットワークドライブのマウント、rclone、グローバル IP フィルター、HTTP/3 | 計画中。コミュニティの要望に応じて優先度を決定 |

## 意図的な違い

- バイナリを上書きするオンライン自動更新は内蔵せず、アップグレードはパッケージマネージャーまたは Docker に任せます。
- リモートからの設定配信は行わず、端末情報も送信しません。
- 設定は平文で保存され、機密フィールドは API 出力でマスクされます。

## 移行

両者は併用でき、モジュール単位で切り替え、いつでも元に戻せます。[移行ガイド](/ja/docs/guide/migration) を参照してください。
