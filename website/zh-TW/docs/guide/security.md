# 安全模型與隱私承諾

Gately 執行在網路邊界，經手 DNS 服務商金鑰、憑證私鑰與各類憑據，因此安全與透明是首要設計目標。

## 隱私承諾

- **預設零外連**：不連線任何專案方伺服器，不回報裝置資訊，不下發遠端設定。
- **對外位址可見可改**：公網 IP 查詢、STUN 伺服器等位址都在介面中顯示，可修改或關閉。
- **第三方登入自主**：GitHub、Google、QQ、OIDC 登入使用你自己申請的 OAuth 應用程式，不經過任何中轉。
- **自主升級**：程式不會在背景替換自身執行檔，升級時機由你決定。

## 資料保護

- 設定為純文字 JSON，檔案權限 0600，可稽核、可回復。
- 敏感欄位在 API 輸出中會遮蔽。
- cloudflared 的權杖透過環境變數傳遞，不會出現在行程清單中；frp、Tailscale 的權杖與金鑰以 0600 權限儲存。

## 驗證與存取控制

- bcrypt 密碼雜湊，HMAC 簽章工作階段權杖；
- 兩步驟驗證（TOTP，已通過 RFC 6238 測試向量驗證）；
- 登入失敗限流；
- 安全入口、僅限內網存取、管理介面 HTTPS；
- 多權杖 API：每個權杖只擁有建立時勾選的模組讀寫權限，可設定到期時間，並記錄最近使用的來源 IP；帳號、兩步驟驗證、權杖管理以及備份、還原、重新啟動、系統設定介面只接受登入工作階段，詳見 [API 權杖與 OpenAPI](/zh-TW/docs/reference/api)；
- 站台存取控制：驗證失敗自動封鎖、GeoIP 國家過濾、路徑規則，詳見 [Web 服務](/zh-TW/docs/modules/web)；
- 設定備份支援加密（scrypt + AES-GCM），詳見 [設定備份](/zh-TW/docs/modules/backup)。

## 高風險功能的預設值

本機 Shell 終端機預設關閉。SSH 終端機採用「首次信任」策略記錄主機金鑰指紋。
