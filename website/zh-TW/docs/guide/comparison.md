# 與 Lucky 比較

Gately 受 Lucky 啟發，以開源方式涵蓋常用能力，並可匯入現有設定。Lucky 在功能廣度和使用者累積上都走在前面，沒有 Lucky 就不會有 Gately，在此致謝。

## 理念差異

| 項目 | Gately | Lucky |
| --- | --- | --- |
| 原始碼 | 開源（Apache-2.0） | 閉源 |
| 設定檔 | 純文字 JSON，可用 git 管理 | 專有格式（`.lkcf`） |
| 官方服務 | 預設無，所有對外位址可改可關 | 提供線上更新、第三方登入中轉等官方服務 |
| 第三方登入 | 使用自己的 OAuth 應用程式 | 經官方中轉服務 |
| 升級方式 | Docker / 套件管理員 | 內建線上自動更新 |
| 功能廣度 | 涵蓋常用核心能力 | 更豐富，如 DLNA、網路硬碟掛載等 |

## 功能涵蓋

| 能力 | Gately |
| --- | --- |
| 動態網域 | ✅ |
| STUN 穿透 | ✅ |
| 連接埠轉發 | ✅ |
| SSL 憑證 | ✅ |
| Web 服務（反向代理） | ✅ |
| WAF | ✅ |
| Tailscale / frp / cloudflared | ✅ |
| Docker 管理 | ✅ |
| Web 終端機 | ✅ |
| WebDAV / FTP / 儲存管理 | ✅ |
| 網路喚醒 / 排程工作 | ✅ |
| 通知中心 / 設定備份 / 網路診斷 | ✅ |
| API 權杖 / OpenAPI / 命令列 / MCP | ✅ |
| DLNA、網路硬碟掛載、rclone、全域 IP 過濾、HTTP/3 | 規劃中，視社群需求排程 |

## 有意為之的差異

- 不內建線上自動更新覆蓋執行檔，由套件管理員或 Docker 負責升級。
- 不下發遠端設定，不回報裝置資訊。
- 設定以純文字儲存，敏感欄位在 API 輸出中會遮蔽。

## 遷移

兩者可以並存，逐個模組切換，隨時退回。請見 [遷移指南](/zh-TW/docs/guide/migration)。
