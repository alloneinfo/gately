# 連接埠轉發

把本機監聽的連接埠轉發到另一台裝置或服務。

## 能力

- TCP 與 UDP；
- IPv4 與 IPv6，v4 / v6 之間可互相轉發；
- 連接埠範圍與多連接埠；
- 多目標與容錯移轉；
- 連線數限制；
- 流量統計與執行日誌。

## 典型情境

- 把 NAS 的服務連接埠公開到統一入口；
- 在 IPv6 與 IPv4 之間做互通轉發；
- 為一個服務設定主備兩個後端。

## 部署提示

連接埠轉發直接監聽主機的連接埠，Docker 部署建議使用 `--network host`。

## 從 Lucky 遷移

規則可從 `lucky_portforward.lkcf` 匯入；TLS / 串流加密、限速等選項暫不支援，匯入時會給出提示。
