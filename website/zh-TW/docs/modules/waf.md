# WAF 防火牆

基於 [Coraza](https://coraza.io/) 與 OWASP CRS v4 的 Web 應用程式防火牆，可掛接到 [Web 服務](/zh-TW/docs/modules/web) 的站台。

## 能力

- 內建 OWASP CRS v4 規則集，可依規則檔案啟用；
- 支援自訂 SecLang 規則；
- 攔截模式與僅偵測模式；
- 多個實例，站台視需要引用。

## 使用建議

1. 新站台先使用「僅偵測」，觀察一段時間的日誌，確認沒有誤判；
2. 針對誤判調整規則檔案或新增自訂例外；
3. 再切換為「攔截」。

## 驗證

WAF 使用真實攻擊載荷測試，涵蓋路徑穿越等攻擊的攔截。
