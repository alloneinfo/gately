# Gately v0.5.7 發布

2026 年 10 月 24 日

這一版為儲存掛載加上 SMB 共用（[#14](https://github.com/wangwanjie/gately/issues/14)），重做了主題，並讓管理介面在弱網與多分頁下更省流量、更輕快。

[下載 v0.5.7](/zh-TW/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.7) · [檔案服務文件](/zh-TW/docs/modules/tools)

## SMB 共用掛載

- 掛載位址寫成 `smb://主機[:連接埠]/共用名稱[/子目錄]`，可連線 Windows 共用、NAS 與 Samba，使用 SMB2/3；
- 支援使用者名稱、密碼與選填的網域或工作群組，使用者名稱留空時以來賓身分連線；
- 與本機目錄、WebDAV 掛載一樣可以線上管理檔案，也可以作為定時備份的目的地；
- 首次使用時才建立連線，伺服器中斷後在下一次操作時自動重新連線；帳號密碼錯誤、共用不存在時給出明確提示。

## 選單改名

側邊欄「網路儲存」改為「檔案服務」，其中「儲存管理」改為「儲存掛載」（Gately 連線本機目錄、遠端 WebDAV 或 SMB 共用），「WebDAV」改為「WebDAV 服務」（Gately 把本機目錄分享出去，與「FTP 服務」並列）。概覽、匯入報告、API 權杖權限與 API 文件中的模組名稱同步更新。

## 主題

- 15 個色系分為 Gately 原創（翠綠、海洋、清新、櫻花、暮光、午夜、龐克）與經典配色（GitHub、Nord、Dracula、Catppuccin、Tokyo Night、Gruvbox、Rosé Pine、Solarized），每個色系都有亮色與暗色，跟隨系統對所有色系都可用；
- 任一色系都可以換成 10 種預設主色之一或用取色器自選，Logo 與登入頁漸層隨之變化；圓角可選直角、跟隨色系或圓潤；
- 主題面板支援懸停預覽，切換時有圓形展開動畫；
- Web 終端機新增「跟隨介面主題」配色並作為預設，Docker 容器終端機也使用同一配色偏好；
- 所有色系的文字、次要文字、主色與按鈕都通過了對比度檢查。

舊版本選擇的主題會在首次開啟時自動遷移，原來的「暗黑」對應翠綠的暗色版本。

## 更快、更省流量

- 管理介面的 API 回應與首頁使用 br / gzip 壓縮，腳本與樣式在建置時預先壓縮：250 KB 的 API 描述傳輸約 15 KB，850 KB 的主腳本約 270 KB；
- 程式縮小約 11%，Linux amd64 約 32 MB；
- 分頁切到背景時，15 個頁面與面板的定時重新整理自動暫停，切回時立即重新整理一次；上一次請求尚未返回時跳過本輪；
- 日誌卡片首次只拉取最近 200 筆，更早的日誌點「載入更早的日誌」逐頁補充；日誌 API 新增 `limit` 與 `before` 參數；
- 動態網域頁面一次往返即載入完成。

## 修復

- 開啟壓縮的 Web 服務站台：經 HTTP 存取（瀏覽器只宣告 gzip）時，反向代理上游已經 gzip 的回應被再壓縮一次，瀏覽器收到亂碼；
- 入侵防護：儲存設定或模組重新啟動後，丟棄封包數、誘餌連接埠與掃描偵測的命中計數歸零；
- 語言選單、主題面板、使用者選單開啟時，滾輪與觸控仍會捲動下方頁面；
- 線上升級失敗後立即重試，偶爾提示「正在升級中，請稍候」。

## 升級提示

- 升級方式：Linux 二進位在「關於」頁直接升級；Docker 拉取新映像後重建容器；飛牛在應用中心安裝新版 `.fpk`；OpenWrt 安裝新版 `.ipk` / `.apk`。
- 設定格式沒有變化，可以直接升級；主題選擇儲存在瀏覽器本機，升級後各瀏覽器第一次開啟時自動遷移。
- 選單改名不影響既有設定與 API 路徑，`/api/storage/*` 與 `/api/webdav/*` 保持不變。
