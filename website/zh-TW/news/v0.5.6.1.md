# Gately v0.5.6.1 發布

2026 年 10 月 22 日

這是 v0.5.6 的修復版本，只涉及 Docker 映像，建議 Docker 使用者升級。

[下載 v0.5.6.1](/zh-TW/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.6.1)

## 修復主機 nft 當機

v0.5.6 的 Docker 映像內建 nftables 1.1.5。nftables 從 1.1.2 起會在集合上寫入舊版不認識的中繼資料，主機上 1.1.1 之前的 nft（如 Debian 12、飛牛 fnOS 內建的 1.0.6）執行 `nft list ruleset` 時會因此當機；Gately 自身讀寫規則不受影響。

這一版把映像中的 nftables 固定為 1.1.1。升級後 Gately 啟動時會重建 `inet gately` 表，主機的 nft 即可恢復正常。飛牛安裝包、OpenWrt 安裝包與二進位部署使用系統內建的 nft，不受影響。

## 升級提示

- Docker 拉取新映像後重建容器即可。其餘部署方式與 v0.5.6 相同，可以不升級。
