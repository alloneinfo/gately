# Gately v0.6.0 發布

2026 年 10 月 27 日

這一版讓 frp 支援多實例，Web 服務新增依登入使用者分流（[#29](https://github.com/wangwanjie/gately/issues/29)）、站點分組排序（[#28](https://github.com/wangwanjie/gately/issues/28)）與轉發登入 Cookie（[#30](https://github.com/wangwanjie/gately/issues/30)），並修復子網域憑證簽發失敗（[#27](https://github.com/wangwanjie/gately/issues/27)）。

[下載 v0.6.0](/zh-TW/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.0)

## frp 多實例

- 可以同時執行多個 frpc 實例（各連一台 frps）和多個 frps 實例（各監聽自己的埠），每個實例是獨立行程，有自己的設定檔與日誌來源，可單獨啟停、重新啟動、編輯和刪除；
- 代理歸屬某個 frpc 實例，列表可依實例篩選；修改代理只重新啟動設定有變化的實例；刪除 frpc 實例時一併刪除它的代理；
- 程式路徑移到單獨的「程式」卡片；
- 匯入 ini / toml 設定時可以匯入到已有實例或新建實例，Lucky 匯入會帶上全部 frpc / frps 實例；
- 舊版的單個 frpc / frps 設定在升級後自動遷移為名為 frpc / frps 的實例，權杖和代理保持不變。

詳見 [組網與穿透](/zh-TW/docs/modules/tunnels)。

## Web 服務

- **依登入使用者分流**：開啟基本認證、網頁認證或轉發認證的反向代理站點，可以把指定使用者轉發到各自的後端，類似 nginx 的 `map $remote_user $backend`。使用者可以是站點使用者、共用使用者、第三方登入的 `提供方:ID`，或轉發認證回傳的 `Remote-User`；未列出的使用者和公開路徑上未登入的訪客使用站點後端。還可以用 `X-Remote-User` 這類請求標頭把使用者名稱傳給後端，訪客自己傳送的同名請求標頭（包括用底線代替連字號的寫法）總會被刪除。
- **站點分組、排序與搜尋**：站點可以設定分組，列表依監聽顯示可摺疊的分組；「排序」模式下可以上下移動或拖曳站點、整組移動，也可以調整監聽順序；頁首搜尋框依網域、名稱、分組、後端和備註篩選。順序只影響列表顯示，與網域比對無關。
- **轉發 Gately 登入 Cookie**：反向代理站點的新選項。開啟後，單一登入與站點工作階段 Cookie 會原樣轉發給後端，這樣公網 Gately 只負責 WAF 和存取控制，由內網 Gately 負責網頁認證與單一登入。該選項不能與本站點的認證同時開啟。

詳見 [Web 服務](/zh-TW/docs/modules/web)。

## 憑證

主網域留空時，DNS-01 驗證會先用 SOA 查詢驗證記錄所在的權威區域。子網域單獨託管在另一家 DNS 服務商（如 web.example.com 與 example.com 分開託管）和多級後綴都能正確識別。查詢失敗、或查到的區域比可註冊網域還短（例如本地 DNS 覆寫了上層網域）時，依網域推斷主網域，原因記入日誌。每張憑證設定的 DNS 伺服器只用於這張憑證。

## 顯示已儲存的密碼

被遮罩的密碼、權杖和金鑰旁邊有眼睛按鈕，點擊後從新的 `.../secrets` 介面取回明文：

- 需要寫入權限，唯讀帳號和唯讀 API 權杖回傳 403，每次查看都記入稽核日誌；
- Web 終端的連線與認證預設密碼和開啟終端一樣，需要先通過終端的二次驗證；
- 用 bcrypt 儲存的網頁使用者密碼、OIDC 用戶端密鑰和私鑰不會回傳；
- 開啟兩步驟驗證的共用使用者可以重新查看 QR 碼；
- `gately mcp` 預設的唯讀模式不提供這類介面，加 `--write` 才會提供。

## 升級提示

- 升級方式：Linux 二進位在「關於」頁直接升級；Docker 拉取新映像後重建容器；飛牛在應用中心安裝新版 `.fpk`；OpenWrt 安裝新版 `.ipk` / `.apk`。
- 設定格式向下相容，可以直接升級。frp 舊設定會在首次啟動時遷移為實例，舊版產生的 `frp/frpc.toml`、`frp/frps.toml` 會被刪除。
- 介面 `/api/frp/client` 與 `/api/frp/server` 已移除，改為 `/api/frp/clients`、`/api/frp/servers` 與 `/api/frp/settings`。用腳本呼叫舊介面的需要相應修改。
- Docker 映像倉庫密碼的遮罩佔位符改為與其他模組一致的 8 個星號，舊的 6 個星號仍能識別。
