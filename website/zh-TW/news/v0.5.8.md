# Gately v0.5.8 發布

2026 年 10 月 25 日

這一版讓 Gately 可以作為 OIDC 身分提供者，新增 SMB 檔案共用（[#15](https://github.com/wangwanjie/gately/issues/15)），為所有日誌加上篩選（[#16](https://github.com/wangwanjie/gately/issues/16)），並支援調整 WAF 規則組的順序（[#17](https://github.com/wangwanjie/gately/issues/17)）。

[下載 v0.5.8](/zh-TW/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.8) · [OIDC 單一登入文件](/zh-TW/docs/modules/oidc)

## OIDC 單一登入

Web 服務內建 OpenID Connect 身分提供者，Gitea、OpenList、Grafana 等支援 OIDC 登入的應用程式可以直接用共用使用者登入，並能區分是誰登入，可以取代 Authelia 的 OIDC 功能。

- 在「Web 服務 → 全域設定 → OIDC 身分提供者」中填寫簽發者位址並新增用戶端即可，簽發者網域不需要建站台；
- 共用使用者新增選填的電子郵件、顯示名稱和群組，作為 `email`、`name`、`groups` 聲明提供給應用程式，應用程式可據此自動建立帳號、依群組授予管理員權限；
- 每個用戶端可限定允許登入的使用者或群組；支援 PKCE、更新權杖、`prompt=none` / `prompt=login`，公開用戶端（單頁應用程式、手機 App）必須使用 PKCE；
- 登入沿用網頁驗證的登入頁和 TOTP 二次驗證，簽發者位於單一登入網域內時，登入過任一站台就不必再登入應用程式；
- 修改密碼或 TOTP、刪除使用者、移出允許清單後，已簽發的權杖立即失效；`sub` 使用共用使用者的固定 ID，改名不變；
- 文件附 Gitea、OpenList、Grafana 的設定範例，均已對照真實應用程式驗證。

## SMB 服務

「檔案服務」新增「SMB 服務」，把本機目錄分享給 Windows 檔案總管、macOS Finder、Linux 以及手機、電視上的 SMB 用戶端：

- 支援 SMB 2.0.2 ~ 3.1.1、NTLMv2 驗證與簽章，可要求 SMB 3 加密；
- 使用者設定與 FTP、WebDAV 相同，每個使用者只能看到自己的共用，目錄可單獨設為唯讀；
- 頁面列出每個共用的連線位址，可開啟 Bonjour 廣播讓 Finder 直接發現；
- 僅 Linux 與 macOS 上可用。Windows 只能連線 445 連接埠，NAS 內建的 Samba 已占用時需改用其他連接埠。

## 日誌篩選

「系統日誌」和每個模組的日誌卡片都可以依等級、來源、關鍵字（支援片語和排除詞）、用戶端 IP 或網段、時間範圍篩選，Web 服務還可以依站台、網域和狀態碼篩選。篩選在伺服器端完成，「載入更早的日誌」會繼續搜尋已寫入磁碟的日誌檔。Web 服務存取日誌和 WAF 命中日誌記錄了用戶端 IP、網域、狀態碼與規則 ID，點擊日誌中的標籤即可依該值篩選。日誌 API 支援相同的篩選參數。

## Web 服務與 WAF

- 站台的請求標頭、回應標頭改為逐行編輯，名稱和值可從常用項目中選擇（HSTS、CSP、X-Frame-Options 等），一鍵補齊常用安全標頭，並即時檢查格式與常見誤用；固定文字站台的 Content-Type 可從常用類型中選擇；
- 名稱或值含非法字元的請求標頭會在儲存時被拒絕，之前這類設定會讓整個站台回傳 502；
- 反向代理的「選項」旁新增說明，逐項解釋六個選項的作用與適用情境；
- WAF 規則組可上移、下移。放行規則（`allow`、`ctl:` 等）要放在 OWASP CRS 之前，`SecRuleRemoveById` 等移除指令要放在 CRS 之後，介面與文件都有說明。

## 修復

- FTP、WebDAV 使用者改名但不重新輸入密碼時，儲存會失敗。

## 升級提示

- 升級方式：Linux 二進位在「關於」頁直接升級；Docker 拉取新映像後重建容器；飛牛在應用中心安裝新版 `.fpk`；OpenWrt 安裝新版 `.ipk` / `.apk`。
- 設定格式向下相容，可以直接升級。共用使用者在首次啟動時自動產生固定 ID，並寫回設定檔。
- 網頁驗證登入表單會拒絕來自其他網站的提交，正常登入不受影響。
