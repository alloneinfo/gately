# Gately v0.5.9 發布

2026 年 10 月 26 日

這一版新增託管 File Browser（[#23](https://github.com/wangwanjie/gately/issues/23)）和 IP 位址憑證（[#24](https://github.com/wangwanjie/gately/issues/24)），並讓託管的外部程式都可以線上安裝和回滾。

[下載 v0.5.9](/zh-TW/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.9)

## File Browser

「檔案服務」新增「File Browser」，託管網頁檔案管理器 [FileBrowser Quantum](https://github.com/gtsteffaniak/filebrowser)。原版 filebrowser/filebrowser 已在 2026 年封存、不再修復安全問題，因此選用仍在維護的 Quantum 分支。

- 每個實例可設定監聽位址與連接埠、存取路徑（便於按路徑反向代理）、一個或多個共用目錄（可單獨設為唯讀）、介面語言與登入有效期；
- 登入方式可選帳號密碼、信任反向代理傳入的使用者名稱請求標頭（搭配 Web 服務的網頁驗證），或不登入（會有醒目提示）；
- 管理員密碼透過環境變數傳給 File Browser，每次啟動同步，不寫入任何檔案；
- 共用目錄不存在時拒絕啟動，刪除實例時一併刪除其資料目錄（使用者、分享連結、快取），共用目錄裡的檔案不受影響。

詳見 [檔案服務](/zh-TW/docs/modules/tools)。

## IP 位址憑證與短期憑證

ACME 憑證新增「憑證設定檔」，可選 CA 預設、Let's Encrypt 的短期憑證（約 6 天）或 CA 支援的其他設定檔名稱。

- 網域清單中可以直接填寫公網 IPv4、IPv6 位址，簽發 IP 位址憑證；IP 憑證需使用 HTTP-01 驗證，Let's Encrypt 需選短期憑證，編輯器會提示並可一鍵設定；
- 預置 CA 只為公網位址簽發，內網、迴環與 100.64.0.0/10 位址會被拒絕；自建 CA（如 step-ca）不受這些限制，仍需 HTTP-01 驗證；
- 不帶 SNI 的 TLS 連線（按 IP 存取）自動使用與本機位址相符的 IP 憑證；
- 短期憑證在到期前按「短期憑證提前小時數」續簽（預設 24 小時，最多 80 小時），失敗後每小時重試；憑證卡片顯示「短期」標籤與剩餘小時數。

詳見 [SSL 憑證](/zh-TW/docs/modules/ssl)。

## 託管程式線上安裝

frp、cloudflared、Tailscale 與 File Browser 的頁面都有「線上安裝」卡片：

- 安裝最新正式版或指定版本（也可降級），下載後校驗 SHA-256、確認能在本機執行後才替換，並自動重新啟動使用該程式的處理程序；
- 每個程式可單獨設定下載代理（http、https、socks5），留空沿用全域「更新代理」；
- 替換下來的舊版本保存在設定目錄的 `bin/.versions/` 下，最多 3 個，可一鍵回滾或刪除；
- 「解除安裝」刪除安裝的程式與全部舊版本，模組設定保留；
- 頁首的「恢復預設設定」停止處理程序並把模組設定恢復為預設，舊設定保存在設定歷史中；
- Tailscale 只在 Linux 上提供線上安裝（官方沒有 macOS、Windows 的靜態套件）。

程式尋找順序改為：頁面中填寫的路徑 → 設定目錄下的 `bin/` → `PATH`，線上安裝的程式優先生效。詳見 [組網與穿透](/zh-TW/docs/modules/tunnels)。

## 檔案服務共用使用者

WebDAV、FTP、SMB 的共用使用者改到「檔案服務 → 檔案共用使用者」獨立頁面編輯，頁面列出每個服務是否啟用、是否允許共用使用者，以及被同名本機使用者覆蓋的使用者。各服務頁面只保留「允許共用使用者登入」開關。新增 API `GET/PUT /api/fileusers` 與權杖權限 `fileusers:read`、`fileusers:write`，原有的 `/api/<服務>/shared-users` 繼續可用。

## 升級提示

- 升級方式：Linux 二進位在「關於」頁直接升級；Docker 拉取新映像後重建容器；飛牛在應用中心安裝新版 `.fpk`；OpenWrt 安裝新版 `.ipk` / `.apk`。
- 設定格式向下相容，可以直接升級，已有憑證不會因升級重新簽發。
- 程式尋找順序變化後，若設定目錄的 `bin/` 下已有同名程式，會優先使用它而不是 `PATH` 中的程式。
- 已在「功能模組」中關閉的檔案服務不再阻止修改共用使用者。
