# Gately v0.5.5 發布

2026 年 10 月 21 日

這一版圍繞「從 nginx 搬過來、搬過來之後少操心」：現有的 nginx 站點可以直接匯入，憑證續期後自動送到其他主機和容器，網盤與 WebDAV 站點也能掛 WAF，IP 存取控制可以引用定時更新的省市 IP 清單，網路自檢能提前發現缺憑證的站點和 frp 衝突。

[下載 v0.5.5](/zh-TW/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.5)

## 匯入 nginx 設定

「Web 服務」頁新增「匯入 nginx」。在 nginx 所在主機執行 `nginx -T`，把完整輸出貼上即可，include 的檔案會像 nginx 一樣展開。

- 匯入前先預覽：依監聽連接埠列出每個站點的類型、後端或目錄、來源檔案與行號，以及使用了變數、正規表示式 location、缺少憑證等需要注意的地方；
- 能轉換反向代理（含 upstream 的權重、備用與負載平衡策略）、靜態目錄、跳轉、固定內容、回應標頭與請求標頭、壓縮、`allow` / `deny`，以及 location 層級的分路徑後端、存取控制與跳轉；
- `auth_request` 轉換為轉發驗證，Authelia 的常見寫法（`set` 變數、`error_page 401` 登入跳轉）可以直接轉換，只在部分 location 啟用時轉換為「只對指定路徑驗證」；`auth_basic` 轉換為使用共用使用者的基本驗證，匯入後不會出現沒有保護的站點；
- 相同連接埠的站點合併到既有監聽，已存在的網域會略過，可以重複匯入；預設匯入為停用狀態，適合與 nginx 並行逐一核對。

這個功能用一份真實的正式環境設定（77 個站點、Authelia、upstream）驗證過，轉換結果與手動遷移一致。詳見 [Web 服務 · 匯入 nginx 設定](/zh-TW/docs/modules/web#import-nginx)。

## 憑證自動部署

憑證的編輯框新增「自動部署」，簽發、續期或更新後自動執行：

- **上傳到 SSH 主機**：選擇 Web 終端中既有的 SSH 連線，憑證寫入遠端目錄後執行指令，例如 `systemctl reload nginx`，指令中可用 `$certName`、`$certDir`、`$certFile`、`$keyFile`；檔案先寫入暫存檔再取代，私鑰權限為 0600；
- **重新啟動本機容器**：憑證變動後依序重新啟動所選的 Docker 容器。

自動部署不會信任未知主機，SSH 連線需要先在 Web 終端中連線一次。失敗時每小時重試，並發出新的「憑證：部署失敗」通知；憑證卡片上的「立即部署」可以馬上執行並顯示每個目標的結果。詳見 [SSL 憑證](/zh-TW/docs/modules/ssl)。

## WAF：大型檔案上傳與 WebDAV

- **請求內容檢查上限**可調（預設 12.5 MB，最大 1024 MB），超過上限時可以拒絕，也可以只檢查前段、其餘原樣轉發；
- **略過請求內容的路徑**：上傳介面不檢查請求內容，請求標頭、URL 與參數照常檢查；
- **相容 WebDAV 與上傳**：放行 PUT、PROPFIND、MKCOL、MOVE、COPY、LOCK 等方法與 `Lock-Token`、`If`、`Content-Range` 請求標頭，不再限制上傳的內容類型，網盤、WebDAV、檔案管理站點掛上 WAF 也能正常使用，注入、路徑穿越等攻擊照常攔截；
- 所有實例放行 curl、rclone 上傳大型檔案時帶的 `Expect: 100-continue`，之前 OWASP CRS 4 會攔截這類上傳。

詳見 [WAF 防火牆](/zh-TW/docs/modules/waf)。

## 訂閱 IP 清單

在「Web 服務 → 全域設定」依網址訂閱 IP 清單並定時重新整理，例如 [metowolf/iplist](https://github.com/metowolf/iplist) 的省市 IP 段。站點與路徑規則的白名單、黑名單可以引用多個清單，與手動填寫的 IP 段一起判斷；下載內容快取在本機，重新啟動後無需連網；內容無法辨識時保留上次的清單。詳見 [Web 服務 · 訂閱 IP 清單](/zh-TW/docs/modules/web)。

## 網路自檢新增兩項

- **HTTPS 站點憑證**：列出沒有符合憑證的網域，這些網域會在 TLS 交握時失敗；
- **frp 衝突**：列出 frpc 中重名的代理，以及 frps 回報的代理名稱、網域或遠端連接埠衝突。多台裝置複製了同一份 frpc 設定時，後連上的裝置註冊失敗，對應的網站會逾時。

## 其他改進

- 線上升級支援 `v0.5.4.1` 這樣的四段版本號；版本號無法比較時（如開發版）會明確提示，不再顯示「已是最新」。
- 憑證部署、nginx 匯入預覽等介面回傳的說明文字依介面語言顯示。

## 升級提示

- 從 v0.5.4 起，Linux 執行檔部署可以在「關於」頁直接升級到 v0.5.5；Docker 拉取新映像檔後重建容器；飛牛在應用中心安裝新版 `.fpk`；OpenWrt 安裝新版 `.ipk` / `.apk`。
- 已經掛了 WAF 的網盤、WebDAV 站點，升級後在對應 WAF 實例中開啟「相容 WebDAV 與上傳」即可正常上傳。
