# Gately v0.5.8.1 發布

2026 年 10 月 26 日

這是 v0.5.8 系列的功能更新，來自 [issue #18](https://github.com/wangwanjie/gately/issues/18)、[#19](https://github.com/wangwanjie/gately/issues/19)、[#20](https://github.com/wangwanjie/gately/issues/20)、[#22](https://github.com/wangwanjie/gately/issues/22) 的建議。

[下載 v0.5.8.1](/zh-TW/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.8.1)

## 檔案服務共用使用者

WebDAV、FTP、SMB 可以共用一份「共用使用者」，只需維護一次密碼與目錄。三個服務頁面都有「共用使用者」卡片，在任一頁面修改都會同時生效；每個服務以「本服務啟用」開關決定是否接受共用使用者，原有的本機使用者照常使用，同名時以本機使用者為準。只用共用使用者也可以啟用服務。修改後 WebDAV 下一個請求即按新設定校驗，FTP 會中斷已登入的工作階段，SMB 在帳號變化時重新載入。詳見 [檔案服務](/zh-TW/docs/modules/tools#shared-users)。

## 中斷連線站台與存取日誌

站台類型新增「中斷連線」，不回傳任何內容直接中斷，相當於 nginx 的 `return 444`。適合設為預設站台，讓掃描未知網域的請求得不到任何回應，存取日誌記為 444。匯入 nginx 設定時 `return 444` 會轉為這一類型。

Web 服務的存取日誌末尾按 nginx combined 格式附上 Referer 與 User-Agent，便於區分同一出口 IP 後面的不同裝置。詳見 [Web 服務](/zh-TW/docs/modules/web)。

## frps 監聽位址

frps 可以分別設定 frpc 連線連接埠的監聽位址與代理連接埠（HTTP、HTTPS 及 tcp/udp 代理的遠端連接埠）的監聽位址，留空為所有位址。例如把 frps 只監聽在 127.0.0.1，由 Gately 的站台以 websocket 或 wss 轉發給它。詳見 [內網穿透](/zh-TW/docs/modules/tunnels)。

## 複製按鈕與兩步驟驗證

透過 HTTP 存取管理介面時，瀏覽器不提供剪貼簿介面，複製按鈕現在會自動改用相容方式；仍失敗時會選取文字並提示手動複製。兩步驟驗證的輸入框可以被 Bitwarden 等密碼管理器辨識並自動填入驗證碼。

## 升級提示

- 修改共用使用者需要 API 權杖同時具備 `webdav:write`、`ftp:write` 與 `smb:write`；只靠共用使用者啟用的服務不能把共用使用者刪光。
- 「中斷連線」站台不經過認證、存取控制與 WAF，站台的其他設定不生效。
- 存取日誌中過長的位址、Referer 與 User-Agent 會被截斷。
