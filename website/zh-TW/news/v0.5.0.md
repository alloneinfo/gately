# Gately v0.5.0 發布

2026 年 10 月 19 日

Gately 執行在網路邊界，握有 DNS 金鑰和憑證私鑰，所以「看得見」一直是第一原則。v0.5.0 把這條原則從「程式碼開源」延伸到「執行可追溯」：誰在什麼時候改了什麼、設定怎麼變的、下載的程式是不是官方建置，現在都能查得清楚。

[下載 v0.5.0](/zh-TW/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.0)

## 可追溯：操作稽核與設定歷史

- **操作稽核**：登入、每一次設定變更、下載備份或憑證私鑰、開啟終端機，都會記錄操作者、來源 IP、方法與路徑。不記錄請求內容，也不記錄任何金鑰。
- **設定歷史與一鍵回復**：每次覆寫設定檔前自動儲存舊版本，每個設定保留 30 個，可以逐行比對後回復；回復本身也能復原。
- **真實來源**：管理介面放在本機 nginx、haproxy 或 Gately Web 服務之後時，只信任本機代理傳來的位址，僅限內網存取、登入限流和稽核日誌都能看到真實訪客。

詳見 [稽核與設定歷史](/zh-TW/docs/guide/audit)。

## 更安全的登入

- **Passkey 登入**：用指紋、臉部或裝置 PIN 碼取代密碼，只儲存公鑰，無需再輸入兩步驟驗證碼。
- **唯讀帳號**：給家人或同事一個只能檢視的帳號，不能修改設定、下載備份或讀取金鑰。
- **簽章發布**：執行檔和 Docker 映像檔帶有 cosign 簽章、建置來源證明與 SBOM，可以確認下載的就是官方 CI 建置，方法見 [驗證發佈檔案](/zh-TW/docs/guide/verify)。

## 新功能

- **ACME HTTP-01**：沒有受支援的 DNS 服務商時也能自動簽發憑證。
- **HTTP/3（QUIC）**：Web 服務監聽一鍵開啟。
- **連接埠轉發送出 PROXY 協定**：經 haproxy、nginx 多層轉發時保留真實用戶端位址，詳見 [連接埠轉發](/zh-TW/docs/modules/portforward)。
- **DDNS 新增 7 家**：Amazon Route 53、OVHcloud、Gandi、NS1、Bunny DNS、Namecheap、DynDNS2（No-IP、Dynu 等）。
- **通知新增 7 個管道**：ntfy、Gotify、Pushover、Discord、Slack、Server醬、PushPlus，並內建「關鍵故障」「憑證到期」「安全與登入」等規則範本。

## 更省心的維運

- **全域 Prometheus 指標** `/api/metrics`：憑證剩餘天數、DDNS 同步狀態、連接埠轉發流量、站台與後端健康狀態一處抓取，附 Grafana 面板，見 [監控指標](/zh-TW/docs/reference/monitoring)。
- **網路自檢**：一鍵檢查公網 IPv4 / IPv6、電信業者 NAT、系統時間、80 / 443 連接埠、DDNS 解析與憑證到期。
- **首次啟動引導**：修改密碼、兩步驟驗證 / Passkey、自檢、從 Lucky 匯入、通知設定一頁完成。
- **部署**：`GATELY_INITIAL_PASSWORD` 指定初始密碼，`-apply` 宣告式設定目錄便於 GitOps，新增 systemd 與 OpenWrt 服務範本，見 [安裝部署](/zh-TW/docs/guide/install)。

## 升級提示

- Docker：拉取新映像檔後重建容器即可；執行檔：替換執行檔後重新啟動。
- 連接埠轉發開啟 PROXY 協定後，目標（例如 haproxy 的 `accept-proxy`）必須接收它。若要降級到 v0.4.x，請先撤掉目標上的 PROXY 接收設定。
- 信任本機代理預設開啟，可在「設定 → 存取控制」關閉。
- 由於加入 QUIC，單一檔案大小約 32 MB。
