# Вышла Gately v0.5.4

21 октября 2026 г.

Этот релиз посвящён установке и обновлению. Бинарные установки в Linux (systemd, LXC-контейнеры PVE, OpenWrt при ручной установке и т. п.) теперь обновляются прямо из интерфейса управления, а пользователи OpenWrt и iStoreOS могут ставить Gately системным менеджером пакетов.

[Скачать v0.5.4](/ru/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.4)

## Онлайн-обновление

Нажмите «Проверить обновления» на странице «О программе», и диалоговое окно покажет новую версию, дату релиза и заметки к нему. Нажмите «Обновить», и Gately:

1. скачает с GitHub пакет релиза для этой платформы;
2. сверит его SHA-256 с `checksums.txt` того же релиза;
3. пробно запустит новый бинарный файл, чтобы убедиться, что он работает на этой машине;
4. заменит исполняемый файл и перезапустится, сохранив предыдущую версию рядом как `gately.old`, чтобы можно было откатиться.

Диалог показывает текущий этап, ход и скорость загрузки, а до замены бинарного файла обновление можно в любой момент отменить. После перезагрузки страницы диалог продолжает показывать ещё идущее обновление, а при ошибке выводит причину и кнопку повтора.

- **LXC-контейнеры PVE**: контейнеры, созданные из OCI-образа, тоже обновляются онлайн, удалять и пересоздавать их не нужно;
- **Прокси для обновлений**: если GitHub из вашей сети доступен плохо, задайте прокси http, https или socks5 на странице «О программе» или в разделе «Настройки → Сеть и работа»; через него идут и проверка, и загрузка;
- **Офлайн-обновление и откат**: «Загрузить пакет обновления» принимает tar.gz релиза или сам бинарный файл любой версии, поэтому подходит и для отката;
- **Только по команде администратора**: Gately никогда сам не скачивает и не устанавливает версии. Для Docker, fnOS и пакетов OpenWrt показывается их собственный способ обновления.

Подробнее: [Установка · Онлайн-обновление](/ru/docs/guide/install#online-upgrade).

## Пакеты для OpenWrt

К каждому релизу теперь прилагаются пакеты для OpenWrt под amd64 / arm64 / arm / mipsle / mips / riscv64:

- OpenWrt 24.10 и более ранние (включая iStoreOS): `opkg install ./gately_v0.5.4_openwrt_<arch>.ipk`
- OpenWrt 25.12 и новее: `apk add --allow-untrusted ./gately_v0.5.4_openwrt_<arch>.apk`

Служба добавляется в автозагрузку и запускается сразу после установки, интерфейс управления доступен по адресу `http://<адрес роутера>:16680`. Конфигурация хранится в `/etc/gately` и сохраняется при обновлении, удалении пакета и обновлении прошивки; для обновления установите более новый пакет. Перед установкой проверяется архитектура устройства, поэтому выбирайте пакет по `DISTRIB_ARCH` из `/etc/openwrt_release`. Бинарный файл занимает около 35 МБ, так что пакеты подходят для программных роутеров на x86, приставок на ARM64 и других устройств с достаточным объёмом памяти.

Подробнее: [Установка · OpenWrt](/ru/docs/guide/install#openwrt).

## Исправления

- Сохранение настроек больше не обрывает доступ к интерфейсу управления, открытому через сам Gately: при изменении правила проброса портов цели и маршруты SNI обновляются на месте с сохранением текущих соединений, если слушающие порты, протоколы, режим и ограничения не менялись, а сохранение настроек проброса портов или веб-служб больше не перезапускает все слушатели.
- WAF больше не принимает имена полей JSON вроде `credentials` или `forwardAuth` за обращение к файлам ОС, из-за чего при сохранении заданий DDNS или добавлении слушателей веб-служб возвращался 403.
- Поля ввода списков (домены, списки IP, заголовки, STUN-серверы) больше не съедают Enter, запятые и пробелы при наборе.
- Бинарные файлы mips / mipsle теперь собираются с программной плавающей точкой, поэтому работают на роутерах без аппаратного FPU.
- Сравнение версий теперь следует semver, поэтому новым сборкам больше не предлагается «обновление» до более старой версии.

## Обновление

- Онлайн-обновление появилось в v0.5.4, поэтому этот переход ещё выполняется вручную: замените бинарный файл и перезапустите службу, скачайте новый образ Docker и пересоздайте контейнер или установите новый `.fpk` через Центр приложений fnOS. Дальше обновляться можно со страницы «О программе».
- Если вы ставили Gately на OpenWrt вручную, установите `.ipk` / `.apk` поверх; конфигурация в `/etc/gately` продолжит работать.
