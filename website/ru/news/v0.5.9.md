# Вышла Gately v0.5.9

26 октября 2026 г.

В этой версии Gately управляет File Browser ([#23](https://github.com/wangwanjie/gately/issues/23)), выпускает сертификаты для IP-адресов ([#24](https://github.com/wangwanjie/gately/issues/24)), а все управляемые внешние программы можно устанавливать и откатывать онлайн.

[Скачать v0.5.9](/ru/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.9)

## File Browser

В группе «Файловые сервисы» появилась страница «File Browser», которая управляет веб-файловым менеджером [FileBrowser Quantum](https://github.com/gtsteffaniak/filebrowser). Исходный проект filebrowser/filebrowser в 2026 году переведён в архив и больше не получает исправлений безопасности, поэтому Gately использует поддерживаемый форк Quantum.

- У каждого экземпляра задаются адрес и порт прослушивания, базовый путь (для обратного прокси по пути), один или несколько общих каталогов (каждый можно сделать только для чтения), язык интерфейса и срок действия входа;
- Вход возможен по имени пользователя и паролю, по заголовку с именем пользователя от обратного прокси (вместе с веб-аутентификацией веб-службы) или без входа (с заметным предупреждением);
- Пароль администратора передаётся File Browser через переменную окружения, синхронизируется при каждом запуске и никогда не записывается в файлы;
- Экземпляр, у которого нет общего каталога, не запускается; при удалении экземпляра удаляется и его каталог данных (пользователи, ссылки общего доступа, кэши), а файлы в общих каталогах остаются нетронутыми.

Подробнее: [Файловые сервисы](/ru/docs/modules/tools).

## Сертификаты для IP-адресов и краткосрочные сертификаты

У ACME-сертификатов появился «Профиль сертификата»: профиль CA по умолчанию, краткосрочный профиль Let's Encrypt (около 6 дней) или любое другое имя профиля, которое поддерживает CA.

- Публичные адреса IPv4 и IPv6 можно вписать прямо в список доменов и получить сертификат для IP-адреса. Для IP-сертификатов нужна проверка HTTP-01, а у Let's Encrypt — краткосрочный профиль; редактор подсказывает это и настраивает одним щелчком;
- Предустановленные CA выпускают сертификаты только для публичных адресов, поэтому частные, loopback-адреса и адреса из 100.64.0.0/10 отклоняются; у собственного CA (например, step-ca) этих ограничений нет, но проверка HTTP-01 всё равно нужна;
- TLS-соединения без SNI (доступ по IP) автоматически получают IP-сертификат, соответствующий локальному адресу;
- Краткосрочные сертификаты продлеваются до истечения срока с запасом из настройки «Запас в часах для краткосрочных сертификатов» (по умолчанию 24, максимум 80), после неудачи попытка повторяется каждый час; на карточках сертификатов показываются метка «Краткосрочный» и оставшиеся часы.

Подробнее: [SSL-сертификаты](/ru/docs/modules/ssl).

## Онлайн-установка управляемых программ

На страницах frp, cloudflared, Tailscale и File Browser появилась карточка «Онлайн-установка»:

- Устанавливается последняя стабильная версия или указанная версия (в том числе для понижения). Загрузка проверяется по SHA-256 и пробно запускается на этой машине, прежде чем что-либо заменить, а процессы, использующие программу, перезапускаются;
- Для каждой программы можно задать свой прокси загрузки (http, https, socks5); если поле пустое, используется общий «Прокси для обновлений»;
- Заменённые версии хранятся в `bin/.versions/` в каталоге конфигурации, не больше 3, и к ним можно откатиться или удалить их одним щелчком;
- «Удалить» удаляет установленную программу и все прежние версии, а настройки модуля сохраняет;
- «Сбросить настройки» в заголовке страницы останавливает процессы и возвращает настройки модуля к значениям по умолчанию, а прежние настройки сохраняются в истории конфигурации;
- Онлайн-установка Tailscale доступна только в Linux, поскольку официальных статических пакетов для macOS и Windows нет.

Теперь программы ищутся сначала по пути, указанному на странице, затем в `bin/` в каталоге конфигурации, затем в `PATH`, так что программы, установленные онлайн, начинают использоваться. Подробнее: [Сети и туннели](/ru/docs/modules/tunnels).

## Общие пользователи файловых сервисов

Общие пользователи WebDAV, FTP и SMB теперь редактируются на отдельной странице «Файловые сервисы → Общие пользователи файлов». На ней для каждого сервиса видно, включён ли он и разрешает ли общих пользователей, а также какие общие пользователи перекрыты локальным пользователем с тем же именем. На страницах сервисов остался только переключатель «Разрешить общих пользователей». Новый эндпоинт `GET/PUT /api/fileusers` добавлен вместе с правами токенов `fileusers:read` и `fileusers:write`, прежние эндпоинты `/api/<сервис>/shared-users` продолжают работать.

## Об обновлении

- Как обновиться: установка из бинарного файла Linux обновляется на странице «О программе»; в Docker загрузите новый образ и пересоздайте контейнер; в fnOS установите новый `.fpk` из центра приложений; в OpenWrt установите новый `.ipk` / `.apk`.
- Формат конфигурации обратно совместим, а существующие сертификаты при обновлении не перевыпускаются.
- С новым порядком поиска программа с тем же именем в `bin/` в каталоге конфигурации используется раньше, чем программа из `PATH`.
- Файловые сервисы, выключенные в разделе «Модули», больше не мешают изменять общих пользователей.
