# Вышла Gately v0.5.9.1

26 октября 2026 г.

Это обновление серии v0.5.9 по предложению из [issue #25](https://github.com/wangwanjie/gately/issues/25); кроме того, исправлены два редактора, которые не могли сохранить изменения.

[Скачать v0.5.9.1](/ru/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.9.1)

## HTTP и HTTPS на одном порту

У слушателей с HTTPS появилась опция «HTTP на том же порту», по умолчанию «Отклонять». В режиме «Перенаправлять на HTTPS» `http://хост:порт` перенаправляется на `https://хост:порт` (301 для GET и HEAD, 308 для остальных методов, чтобы сохранить метод и тело); в режиме «Обслуживать» сайты отвечают по незашифрованному HTTP. Это удобно, когда можно пробросить только один порт, а посетители могут ошибиться со схемой, например на нестандартном порту домашнего подключения.

Gately различает TLS и HTTP по первому байту каждого соединения. Заголовки PROXY-протокола по-прежнему читаются раньше, согласование HTTP/2 и проверки ACME HTTP-01 работают как прежде, а `Alt-Svc` отправляется только по HTTPS. При импорте конфигурации nginx директива `error_page 497 https://$host:$server_port$request_uri` в HTTPS server превращается в «Перенаправлять на HTTPS». Подробнее: [Веб-сервис](/ru/docs/modules/web).

## Адреса доступа File Browser

Для экземпляра File Browser можно указать несколько адресов доступа, например `https://files.example.com/` за обратным прокси веб-сервиса. Карточка экземпляра показывает их, а при пустом списке адрес по-прежнему определяется по адресу и порту прослушивания. Схема, хост и порт первого адреса становятся внешним адресом File Browser, который используют ссылки для общего доступа. Подробнее: [Файловые сервисы](/ru/docs/modules/tools#filebrowser).

## Исправления

- Сохранение отредактированного экземпляра File Browser завершалось ошибкой `json: unknown field "state"`. Исправлено.
- Сохранение отредактированного туннеля Cloudflare завершалось той же ошибкой `json: unknown field "state"`. Исправлено.

## Замечания по обновлению

- «HTTP на том же порту» по умолчанию выключен, поэтому существующие слушатели работают как раньше. Изменение опции перезапускает слушатель и разрывает открытые соединения.
- В режиме «Обслуживать» сайты, открытые по HTTP, не шифруются, и пароли веб-аутентификации и общих пользователей тоже передаются открытым текстом. Для доступа из интернета используйте «Перенаправлять на HTTPS».
