# Вышла Gately v0.5.3

21 октября 2026 г.

Этот релиз посвящён fnOS. Gately теперь устанавливается как нативное приложение fnOS: открывается значком на рабочем столе fnOS, использует ту же точку входа, через которую вы заходите в fnOS, а администраторам fnOS больше не нужно входить повторно. Кроме того, неиспользуемые функциональные модули можно отключить целиком.

[Скачать v0.5.3](/ru/download#fnos) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.3)

## Нативное приложение для fnOS

К каждому релизу прилагаются офлайн-пакеты для fnOS: `gately_0.5.3_fnos_x86.fpk` (Intel / AMD) и `gately_0.5.3_fnos_arm.fpk` (ARM). Устанавливаются они в fnOS через «Центр приложений → Ручная установка».

- **Работа с единым шлюзом fnOS**: значок на рабочем столе открывает интерфейс управления по пути `/app/gately/` через ту же точку входа, что и fnOS. Работают и адрес в локальной сети, и удалённый домен fnOS, открывать или пробрасывать порт 16680 не нужно. Доступ через шлюз контролирует fnOS, открыть его могут только администраторы fnOS.
- **Вход администраторов fnOS по сеансу fnOS**: включите «Вход через fnOS» в разделе «Настройки → Контроль доступа», и администраторы, уже вошедшие в fnOS, попадают в Gately сразу, без пароля и кода двухэтапной проверки. Обычные пользователи fnOS по-прежнему входят сами. После выхода страница входа показывает кнопку «Войти как пользователь fnOS &lt;имя&gt;» и не выполняет повторный вход молча. По умолчанию настройка отключена.
- **Все возможности**: приложение работает от root, поэтому может слушать порты 80/443, управлять Docker и открывать веб-терминал. При удалении конфигурация сохраняется, а для обновления достаточно установить более новый `.fpk`.

Подробнее: [Установка · Нативное приложение для fnOS](/ru/docs/guide/install#fnos).

## Включение и отключение модулей

В разделе «Настройки → Модули» можно отключить модуль целиком. Отключённый модуль по-прежнему загружает конфигурацию, но не запускает службы, не обслуживает API управления (его эндпоинты возвращают 403) и скрыт из интерфейса; конфигурация сохраняется и возвращается при повторном включении. Модули, от которых зависят другие, отключить нельзя, а изменения вступают в силу после перезапуска. Если вы пользуетесь лишь несколькими функциями, так можно сократить число слушающих служб и доступных эндпоинтов.

## Другие улучшения

- Интерфейс управления теперь собирает переводы каждого языка в один файл, поэтому число запросов при первой загрузке сократилось примерно со 170 до 75; если лениво загружаемая страница или таблица стилей не загрузилась, страница один раз перезагружается.
- В документации API описаны переключатели модулей и поля настроек, связанные с fnOS.

## Обновление

- Docker: скачайте новый образ и пересоздайте контейнер. Бинарный файл: замените исполняемый файл и перезапустите службу.
- Нативное приложение для fnOS и образ Docker используют порт 16680. Перед переходом с образа Docker на нативное приложение остановите контейнер `gately` и скопируйте каталог конфигурации в `var/config` приложения.
