# История изменений

Ниже собраны анонсы крупных релизов. Полный список изменений и файлы для загрузки каждой версии — на странице [GitHub Releases](https://github.com/wangwanjie/gately/releases).

## [v0.5.4](/ru/news/v0.5.4)

21 октября 2026 г. · Онлайн-обновление для бинарных установок в Linux, поэтому LXC-контейнеры PVE больше не нужно пересоздавать; новые пакеты для OpenWrt (.ipk / .apk).

## [v0.5.3](/ru/news/v0.5.3)

21 октября 2026 г. · Нативное приложение для fnOS: работает через единый шлюз fnOS и пускает администраторов fnOS по их сеансу fnOS; функциональные модули можно включать и отключать.

## [v0.5.2](/ru/news/v0.5.2)

20 октября 2026 г. · Маршрутизация по SNI позволяет нескольким службам делить порт 443, веб-службы могут заменить nginx, общие пользователи получили TOTP и единый вход; сравнение производительности с haproxy + nginx.

## [v0.5.0](/ru/news/v0.5.0)

19 октября 2026 г. · Журнал аудита, история конфигурации и откат, Passkey, учётные записи только для чтения, ACME HTTP-01, HTTP/3, протокол PROXY, глобальные метрики Prometheus, самопроверка сети и подписанные релизы.
