# Вышла Gately v0.5.6.2

23 октября 2026 г.

Это исправление в серии v0.5.6. Обновиться рекомендуется при любом способе установки.

[Скачать v0.5.6.2](/ru/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.6.2)

## Docker 29 работает в модуле Docker

Начиная с Docker 25 минимальная поддерживаемая версия API растёт, и Docker 29 требует не ниже 1.44. Gately всегда использовал 1.41, поэтому страница Docker сообщала об ошибке подключения. Теперь при первом подключении Gately читает поддерживаемый диапазон: остаётся на 1.41, если демон её поддерживает, иначе берёт минимальную версию демона, а для движков старше 20.10 — их собственную версию.

## Без входа — сразу на страницу входа

Сессия хранится в cookie, недоступной странице, поэтому без входа интерфейс показывал обзор, пока запрос к API не возвращал 401 и не перенаправлял на вход. Теперь сессия проверяется до показа страницы: без входа сразу открывается страница входа, а после входа — запрошенная страница.

## Cloudflare принимает настройки, импортированные из Lucky

Lucky использует только API-токен Cloudflare, а в поле ID импортированных настроек часто остаётся AccessKey другого провайдера. Gately принимал его за e-mail аккаунта и переходил на Global API Key, из-за чего DDNS и проверка сертификатов падали с 6003 Invalid request headers. Теперь Global API Key используется только если ID — это e-mail, иначе используется API-токен.

## Переименованные записи DDNS синхронизируются сразу

При изменении задачи записи с новым доменом, типом, линией или TTL сохраняли прежнее состояние и считались синхронизированными, поэтому новая DNS-запись не создавалась. Теперь после сохранения они синхронизируются заново.

## Новый дизайн страниц входа и ошибок веб-сервиса

Страница входа сайтов с веб-аутентификацией, страницы ошибок 404 и 502 и страница, которая показывается при неверном защищённом входе в панель управления, теперь оформлены единым карточным дизайном, который следует светлой или тёмной теме системы. Двухэтапная проверка перенесена во всплывающее окно: после проверки имени пользователя и пароля на той же странице открывается поле для кода, которое отправляется автоматически после ввода 6 цифр. Раньше при запросе кода имя пользователя и пароль стирались; теперь вводить их заново не нужно, а при неверном пароле имя пользователя сохраняется. Запросы не из браузера, например из CLI или API, по-прежнему получают простой текст.

## Об обновлении

- Docker: загрузите новый образ и пересоздайте контейнер. Остальные установки можно обновить онлайн в настройках или установив новый пакет.
- Задачи, в которых ID Cloudflare был вручную очищен из-за ошибки 6003, возвращать не нужно.
