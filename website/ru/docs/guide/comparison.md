# Сравнение с Lucky

Gately вдохновлён Lucky: он покрывает основные возможности с открытым исходным кодом и умеет импортировать существующую конфигурацию. По широте функций и размеру аудитории Lucky впереди. Без Lucky не было бы Gately, и мы благодарим его авторов.

## Различия в подходе

| Параметр | Gately | Lucky |
| --- | --- | --- |
| Исходный код | Открытый (Apache-2.0) | Закрытый |
| Файл конфигурации | Обычный JSON, можно вести в git | Собственный формат (`.lkcf`) |
| Официальные сервисы | По умолчанию отсутствуют, все внешние адреса можно изменить или отключить | Онлайн-обновление, ретрансляция сторонней авторизации и другие официальные сервисы |
| Сторонняя авторизация | Собственное OAuth-приложение | Через официальный ретранслятор |
| Обновление | Docker / пакетный менеджер | Встроенное онлайн-самообновление |
| Широта функций | Основные востребованные возможности | Богаче: например, DLNA, монтирование облачных дисков |

## Намеренные отличия

- Нет встроенного онлайн-самообновления, которое подменяло бы бинарный файл: обновлениями занимается пакетный менеджер или Docker.
- Нет удалённой доставки конфигурации и отправки данных об устройстве.
- Конфигурация хранится в открытом виде, а чувствительные поля маскируются в выводе API.

## Миграция

Оба продукта можно запускать одновременно, переключая модули по одному и возвращаясь назад в любой момент. См. [руководство по миграции](/ru/docs/guide/migration).
