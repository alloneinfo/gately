# Быстрый старт

Развёртывание, вход и первое правило за пять минут.

## 1. Запуск

```bash
docker run -d --name gately --network host \
  -v ./gately-data:/etc/gately \
  -v /var/run/docker.sock:/var/run/docker.sock \
  ghcr.io/wangwanjie/gately:latest
docker logs gately 2>&1 | grep -i "initial password"
```

Если управление Docker не нужно, монтирование `docker.sock` можно убрать. Проброс портов, STUN и веб-службы слушают порты хоста, поэтому рекомендуется `--network host`.

## 2. Вход

Откройте в браузере `http://<IP устройства>:16680`, имя пользователя `admin`, пароль — начальный пароль из журнала (выводится только один раз, при первом запуске).

## 3. Базовая защита

Сразу после входа в разделе «Настройки»:

1. смените пароль администратора;
2. включите двухфакторную аутентификацию (TOTP);
3. при необходимости задайте секретный путь входа, доступ только из локальной сети или HTTPS для интерфейса управления.

Дополнительные рекомендации: [Рекомендации по защите](/ru/docs/guide/hardening).

## 4. Первое правило

Выберите модуль под вашу задачу:

| Задача | Модуль |
| --- | --- |
| Публичный IP дома часто меняется, нужен постоянный домен | [Динамический DNS](/ru/docs/modules/ddns) |
| Провайдер не выдаёт фиксированный публичный порт, нужен доступ к домашним сервисам извне | [STUN-обход NAT](/ru/docs/modules/stun) |
| Перенаправить порт на другое устройство в локальной сети | [Проброс портов](/ru/docs/modules/portforward) |
| Открыть несколько внутренних сервисов под одним доменом с HTTPS | [SSL-сертификаты](/ru/docs/modules/ssl) + [Веб-службы](/ru/docs/modules/web) |
| Объединить сети в разных местах | [Tailscale / frp](/ru/docs/modules/tunnels) |

## Миграция с Lucky

Если вы уже используете Lucky, настраивать всё заново не нужно: в разделе «Настройки → Резервное копирование и миграция» импортируйте `.lkcf` или zip с конфигурацией всего сайта. Подробности в [Руководстве по миграции](/ru/docs/guide/migration).
