# Рекомендации по защите

Интерфейс управления контролирует DNS, сертификаты и порты, поэтому рекомендуется настроить его по следующему списку.

## Интерфейс управления

- [ ] Сменить пароль администратора после первого входа
- [ ] Включить двухфакторную аутентификацию (TOTP)
- [ ] Задать секретный путь входа, чтобы интерфейс был доступен только по собственному пути
- [ ] Включить «Только из локальной сети»; для управления извне заходить через VPN (например, [Tailscale](/ru/docs/modules/tunnels))
- [ ] Включить HTTPS для интерфейса, если вы заходите из недоверенных сетей
- [ ] Для скриптов автоматизации и [командной строки / MCP](/ru/docs/guide/cli-mcp) использовать [API-токены](/ru/docs/reference/api) с минимальными правами и сроком действия, не передавая пароль администратора
- [ ] Задать пароль шифрования для [резервных копий конфигурации](/ru/docs/modules/backup) и включить резервное копирование по расписанию
- [ ] Настроить в разделе [Уведомления](/ru/docs/modules/notify) оповещения о входе, сертификатах, сбоях резервного копирования и других событиях

## Внешние сервисы

- При публикации внутренних сервисов через [Веб-службы](/ru/docs/modules/web) включайте HTTPS и добавляйте базовую аутентификацию, веб-аутентификацию или стороннюю авторизацию;
- для публичных сайтов включайте [WAF](/ru/docs/modules/waf): сначала в режиме «только обнаружение», чтобы оценить ложные срабатывания, затем в режиме «блокировка»;
- ограничивайте источники белыми и чёрными списками IP, фильтрацией по странам через GeoIP и автоблокировкой при неудачной аутентификации.

## Docker

Монтирование `docker.sock` равнозначно выдаче root-доступа к хосту. Если [управление Docker](/ru/docs/modules/docker) не нужно, уберите это монтирование.

## Веб-терминал

Локальный Shell по умолчанию отключён. Включайте его только при необходимости и убедитесь, что для интерфейса управления включена двухфакторная аутентификация.

## Резервное копирование конфигурации

Поместите каталог конфигурации в приватный git-репозиторий или регулярно копируйте его. В `ssl.json` находятся закрытые ключи сертификатов, храните его бережно.
