# SSL-сертификаты

Автоматически выпускает и продлевает сертификаты для [веб-служб](/ru/docs/modules/web); их также можно экспортировать для другого ПО.

## Возможности

- Автоматический выпуск и продление по **ACME DNS-01** с использованием DNS-провайдеров из раздела [динамического DNS](/ru/docs/modules/ddns), без открытия портов 80 / 443;
- wildcard-сертификаты и EAB (например, ZeroSSL);
- загрузка существующего сертификата или чтение из файлов;
- вывод в каталог: после изменения сертификата файлы записываются в указанный каталог и запускается скрипт, чтобы другие сервисы могли перезагрузиться.

## Вывод сертификатов

После включения сертификата Gately записывает `.crt`, `.key`, `.pem` и `_issuerCertificate.crt` в каталог вывода и выполняет скрипт, срабатывающий при изменении.

## Замечания по безопасности

Закрытые ключи хранятся в `ssl.json` в каталоге конфигурации. Берегите этот файл, а при добавлении в систему контроля версий убедитесь, что репозиторий закрытый.

## Миграция с Lucky

Уже выпущенные сертификаты импортируются как есть и не запрашиваются повторно до истечения срока. Для ZeroSSL учётные данные EAB из Lucky используются для регистрации нового аккаунта ACME. Подробности см. в [руководстве по миграции](/ru/docs/guide/migration).
