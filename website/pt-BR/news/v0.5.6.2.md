# Gately v0.5.6.2 lançado

23 de outubro de 2026

Esta é uma versão de correção da série v0.5.6. Todas as instalações devem atualizar.

[Baixar v0.5.6.2](/pt-BR/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.6.2)

## Docker 29 funciona no módulo Docker

Desde o Docker 25 a versão mínima de API suportada vem subindo, e o Docker 29 exige pelo menos 1.44. O Gately usava sempre 1.41, então a página Docker dizia que não conseguia conectar. Agora o Gately lê a faixa suportada na primeira conexão: mantém 1.41 se o daemon suportar, senão usa a mínima do daemon, e em motores anteriores ao 20.10 usa a versão do próprio motor.

## Sem sessão, direto para o login

A sessão fica em um cookie que a página não consegue ler, então sem sessão a interface mostrava a visão geral até uma chamada de API retornar 401 e redirecionar. Agora a sessão é verificada antes de exibir a página: sem sessão aparece direto o login e, depois de entrar, você volta à página pedida.

## Cloudflare aceita configurações importadas do Lucky

O Lucky usa só o token de API da Cloudflare, e as configurações importadas costumam manter no campo ID a AccessKey de outro provedor. O Gately tratava isso como o e-mail da conta e usava a Global API Key, então DDNS e validação de certificados falhavam com 6003 Invalid request headers. Agora a Global API Key só é usada quando o ID é um e-mail; nos demais casos usa-se o token.

## Registros DDNS renomeados sincronizam na hora

Ao editar uma tarefa, registros com domínio, tipo, linha ou TTL alterados mantinham o estado anterior e eram tratados como já sincronizados, então o novo registro DNS nunca era criado. Agora eles são sincronizados novamente ao salvar.

## Novo visual das páginas de login e de erro do serviço web

A página de login dos sites com autenticação web, as páginas de erro 404 e 502 e a página exibida ao usar uma entrada de segurança errada no painel agora seguem um mesmo design em cartão, que acompanha o tema claro ou escuro do sistema. A verificação em duas etapas passou para uma janela: depois que usuário e senha são aceitos, abre-se na mesma página uma caixa para o código, enviada automaticamente ao completar 6 dígitos. Antes o usuário e a senha eram apagados quando o código era exigido; agora não é preciso digitar de novo, e uma senha errada mantém o usuário. Requisições fora do navegador, como CLI ou API, continuam recebendo texto simples.

## Notas de atualização

- Docker: baixe a nova imagem e recrie o contêiner. As demais instalações podem atualizar online em Configurações ou instalando o novo pacote.
- Tarefas cujo ID da Cloudflare você apagou manualmente por causa do erro 6003 não precisam ser revertidas.
