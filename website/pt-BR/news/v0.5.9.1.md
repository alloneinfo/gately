# Gately v0.5.9.1 lançado

26 de outubro de 2026

Esta é uma atualização da série v0.5.9, baseada na sugestão da [issue #25](https://github.com/wangwanjie/gately/issues/25), que também corrige dois editores que não conseguiam salvar.

[Baixar v0.5.9.1](/pt-BR/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.9.1)

## HTTP e HTTPS na mesma porta

Listeners com HTTPS ganham a opção “HTTP na mesma porta”, em “Recusar” por padrão. Com “Redirecionar para HTTPS”, `http://host:porta` redireciona para `https://host:porta` (301 para GET e HEAD, 308 para os demais métodos, preservando método e corpo); com “Servir”, os sites respondem por HTTP sem criptografia. Útil quando só é possível mapear uma porta e os visitantes podem errar o esquema, como numa porta não padrão de uma conexão residencial.

O Gately distingue TLS de HTTP pelo primeiro byte de cada conexão. Cabeçalhos do protocolo PROXY continuam sendo lidos antes, a negociação HTTP/2 e os desafios ACME HTTP-01 continuam funcionando e `Alt-Svc` só é enviado por HTTPS. Ao importar configurações do nginx, `error_page 497 https://$host:$server_port$request_uri` em um server HTTPS vira “Redirecionar para HTTPS”. Veja [Serviço web](/pt-BR/docs/modules/web).

## URLs de acesso do File Browser

Uma instância do File Browser pode ter várias URLs de acesso, como `https://files.example.com/` publicada pelo proxy reverso do Serviço web. O cartão da instância as exibe e, com a lista vazia, o endereço continua sendo deduzido do endereço e da porta de escuta. Esquema, host e porta da primeira URL viram a URL externa do File Browser, usada pelos links de compartilhamento. Veja [Serviços de arquivos](/pt-BR/docs/modules/tools#filebrowser).

## Correções

- Salvar uma instância do File Browser editada falhava com `json: unknown field "state"`. Corrigido.
- Salvar um túnel do Cloudflare editado falhava com o mesmo erro `json: unknown field "state"`. Corrigido.
- Com os usuários compartilhados ativados, os logs de escuta do FTP e do WebDAV mostravam 0 usuários ([issue #26](https://github.com/wangwanjie/gately/issues/26)). Agora mostram “N usuários, M deles compartilhados” como o SMB, e o WebDAV registra os novos totais quando os usuários compartilhados mudam.

## Notas de atualização

- “HTTP na mesma porta” vem desativado, então os listeners existentes se comportam como antes. Alterá-lo reinicia o listener e encerra as conexões abertas.
- Com “Servir”, sites acessados por HTTP não são criptografados e as senhas da autenticação web e dos usuários compartilhados também trafegam em texto claro. Para acesso pela internet, use “Redirecionar para HTTPS”.
