# Gately v0.5.5.2 est disponible

22 octobre 2026

Il s'agit d'une version de correction de sécurité. Les utilisateurs de fnOS devraient mettre à jour rapidement.

[Télécharger v0.5.5.2](/fr/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.5.2)

## Permissions des fichiers du répertoire de configuration

Certains systèmes de fichiers ignorent les permissions demandées par un programme à la création d'un fichier. Par exemple, les volumes fnOS montés avec `trimacl` créent tous les nouveaux fichiers et dossiers en `0755`. Sur ces volumes, le contenu suivant créé par Gately était lisible par les autres utilisateurs locaux :

- Les journaux d'exécution (`logs/`) et le journal d'audit (`audit.log`), qui contiennent les IP des clients et les domaines ;
- L'historique de configuration (`history/`), avec les versions précédentes des règles et des identifiants ;
- Les configurations générées par le module frp (`frp/`), qui contiennent le jeton frp ;
- Les caches des listes d'IP abonnées, les sauvegardes locales, les sauvegardes enregistrées automatiquement avant une restauration et le dossier d'état de Tailscale.

Les fichiers de configuration des modules (`*.json`) ont toujours été enregistrés en `0600` et ne sont pas concernés. Les systèmes de fichiers courants comme ext4 ne le sont pas non plus.

Cette version définit explicitement les permissions après la création des fichiers et dossiers et, au démarrage, restreint le contenu existant de ce type dans le répertoire de configuration à `0600` pour les fichiers et `0700` pour les dossiers, en indiquant le nombre d'éléments modifiés dans le journal système. Les programmes placés dans `bin/` et le répertoire de configuration lui-même restent inchangés.

## Notes de mise à jour

- Depuis v0.5.5, les installations par binaire Linux se mettent à jour depuis la page À propos ; avec Docker, récupérez la nouvelle image et recréez le conteneur ; sur fnOS, installez le nouveau `.fpk` depuis le centre d'applications ; sur OpenWrt, installez le nouveau `.ipk` / `.apk`.
- « Rechercher des mises à jour » dans v0.5.4 et antérieures ne comprend pas les numéros de version en quatre parties. Utilisez « Téléverser un paquet de mise à niveau » sur la page À propos, ou passez d'abord à v0.5.5.
- Si vous avez copié des fichiers du répertoire de configuration ailleurs (par exemple une sauvegarde sur un partage NAS), vérifiez vous-même les permissions de ces copies.
