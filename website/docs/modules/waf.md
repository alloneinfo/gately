# WAF 防火墙

基于 [Coraza](https://coraza.io/) 与 OWASP CRS v4 的 Web 应用防火墙，可挂接到 [Web 服务](/docs/modules/web) 的站点。

## 能力

- 内置 OWASP CRS v4 规则集，可按规则文件启用；
- 支持自定义 SecLang 规则；
- 拦截模式与仅检测模式；
- 多个实例，站点按需引用。

## 使用建议

1. 新站点先使用「仅检测」，观察一段时间的日志，确认没有误报；
2. 针对误报调整规则文件或添加自定义例外；
3. 再切换为「拦截」。

## 验证

WAF 使用真实攻击载荷测试，覆盖路径穿越等攻击的拦截。
