# 端口转发

把本机监听的端口转发到另一台设备或服务。

## 能力

- TCP 与 UDP；
- IPv4 与 IPv6，v4 / v6 之间可互相转发；
- 端口段与多端口；
- 多目标与故障转移；
- 连接数限制；
- 流量统计与运行日志。

## 典型场景

- 把 NAS 的服务端口暴露到统一入口；
- 在 IPv6 与 IPv4 之间做互通转发；
- 为一个服务配置主备两个后端。

## 部署提示

端口转发直接监听宿主机端口，Docker 部署推荐使用 `--network host`。

## 从 Lucky 迁移

规则可从 `lucky_portforward.lkcf` 导入；TLS / 流加密、限速等选项暂不支持，导入时会给出提示。
