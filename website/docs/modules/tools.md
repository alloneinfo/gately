# 文件与运维工具

## WebDAV

多用户，每个用户映射到独立目录，可设为只读。

## FTP

FTP 文件服务：多用户、每个用户映射到独立目录，可设为只读，支持 FTPS 与被动端口范围。

## 存储管理

支持本地与远程 WebDAV 挂载，提供在线文件管理。

## 网络唤醒

发送魔术包广播唤醒局域网设备，并探测设备是否在线。

## 计划任务

使用 cron 表达式定时执行命令或发起 HTTP 请求，并保留执行记录。

## 系统与概览

- 概览页展示主机信息：CPU 使用率与负载、内存、磁盘、网卡地址与实时速率、进程资源，以及各模块状态；
- 系统日志页可查看各模块日志；
- 界面提供多款主题（翠绿、海洋、清新、樱花、暮光、暗黑、午夜、朋克与跟随系统）。
