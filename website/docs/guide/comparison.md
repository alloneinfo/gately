# 与 Lucky 对比

Gately 受 Lucky 启发，以开源方式覆盖常用能力，并可导入现有配置。Lucky 在功能广度和用户积累上都走在前面，没有 Lucky 就不会有 Gately，在此致谢。

## 理念差异

| 项目 | Gately | Lucky |
| --- | --- | --- |
| 源码 | 开源（Apache-2.0） | 闭源 |
| 配置文件 | 明文 JSON，可 git 管理 | 专有格式（`.lkcf`） |
| 官方服务 | 默认无，所有对外地址可改可关 | 提供在线更新、第三方登录中转等官方服务 |
| 第三方登录 | 使用自己的 OAuth 应用 | 经官方中转服务 |
| 升级方式 | Docker / 包管理器 | 内置在线自更新 |
| 功能广度 | 覆盖常用核心能力 | 更丰富，如 DLNA、网盘挂载等 |

## 有意为之的差异

- 不内置在线自更新覆盖二进制，由包管理器或 Docker 负责升级。
- 不下发远程配置，不上报设备信息。
- 配置明文存储，敏感字段在 API 输出中脱敏。

## 迁移

两者可以并存，逐个模块切换，随时回退。见 [迁移指南](/docs/guide/migration)。
