# 安全模型与隐私承诺

Gately 运行在网络边界，经手 DNS 服务商密钥、证书私钥与各类凭据，因此安全与透明是首要设计目标。

## 隐私承诺

- **默认零外联**：不连接任何项目方服务器，不上报设备信息，不下发远程配置。
- **对外地址可见可改**：公网 IP 查询、STUN 服务器等地址都在界面中展示，可修改或关闭。
- **第三方登录自主**：GitHub、Google、QQ、OIDC 登录使用你自己申请的 OAuth 应用，不经过任何中转。
- **自主升级**：程序不会在后台替换自身二进制，升级时机由你决定。

## 数据保护

- 配置为明文 JSON，文件权限 0600，可审计、可回滚。
- 敏感字段在 API 输出中脱敏。
- cloudflared 的令牌通过环境变量传递，不会出现在进程列表中；frp、Tailscale 的令牌与密钥以 0600 权限保存。

## 认证与访问控制

- bcrypt 密码哈希，HMAC 签名会话令牌；
- 两步验证（TOTP，通过 RFC 6238 测试向量验证）；
- 登录失败限流；
- 安全入口、仅内网访问、管理界面 HTTPS；
- 用于自动化的 API 令牌。

## 高风险功能的默认值

本机 Shell 终端默认关闭。SSH 终端采用「首次信任」策略记录主机密钥指纹。
