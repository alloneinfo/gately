# Gately v0.5.7 released

October 24, 2026

This release adds SMB shares to Storage Mounts ([#14](https://github.com/wangwanjie/gately/issues/14)), redesigns themes, and makes the management interface lighter on slow links and with many tabs open.

[Download v0.5.7](/en/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.7) · [File Services docs](/en/docs/modules/tools)

## SMB share mounts

- Write the mount address as `smb://host[:port]/share[/subdir]` to connect to a Windows share, NAS or Samba server over SMB2/3;
- A username, password and optional domain or workgroup are supported; an empty username connects as guest;
- Like local and WebDAV mounts, SMB mounts work in the online file manager and as scheduled backup targets;
- The connection opens on first use and reconnects on the next operation after the server drops it; wrong credentials or a missing share give a clear error.

## Menu renamed

The sidebar group Network Storage is now File Services. Storage becomes Storage Mounts (Gately connecting to local directories, remote WebDAV or SMB shares) and WebDAV becomes WebDAV Service (Gately sharing local directories, alongside FTP Service). Module names in the overview, import reports, API token scopes and the API reference follow the new names.

## Themes

- 15 palettes in two groups, Gately originals (Emerald, Ocean, Fresh, Sakura, Sunset, Midnight, Punk) and classics (GitHub, Nord, Dracula, Catppuccin, Tokyo Night, Gruvbox, Rosé Pine, Solarized); every palette has light and dark, so following the system works for all of them;
- Any palette can take one of 10 preset accents or a color from the picker, and the logo and login gradient follow it; corners can be sharp, the palette's own or round;
- The theme panel previews on hover and switches with a circular reveal;
- The Web terminal gains a "follow interface theme" color scheme, used by default, and the Docker container terminal uses the same preference;
- Text, secondary text, accent and buttons pass a contrast check in every palette.

A theme chosen in an earlier version is migrated the first time the page opens; the old Dark theme becomes the dark variant of Emerald.

## Faster and lighter

- API responses and the home page of the management interface are sent with br or gzip, and scripts and styles are precompressed at build time: the 250 KB API description transfers in about 15 KB and the 850 KB main script in about 270 KB;
- The binary is about 11% smaller, about 32 MB on Linux amd64;
- Timed refreshes of 15 pages and panels pause while the tab is in the background and refresh at once when it is shown again; a round is skipped while the previous request is still running;
- Log cards first fetch the latest 200 entries, with Load earlier logs for older pages; the log API gains `limit` and `before` parameters;
- The DDNS page loads in one round trip.

## Fixes

- Web service sites with compression enabled: over plain HTTP, where browsers only offer gzip, responses already gzipped by the upstream were compressed again and reached the browser garbled;
- Intrusion Prevention: dropped packets, trap port hits and scan detection hits reset to zero after saving the settings or restarting the module;
- With the language menu, theme panel or user menu open, the mouse wheel and touch still scrolled the page below;
- Retrying right after a failed online upgrade sometimes reported "upgrade in progress".

## Upgrade notes

- How to upgrade: Linux binaries upgrade from the About page; Docker pulls the new image and recreates the container; fnOS installs the new `.fpk` from the App Center; OpenWrt installs the new `.ipk` / `.apk`.
- The configuration format is unchanged, so you can upgrade directly. Theme choices are stored in the browser and are migrated the first time each browser opens the page.
- The menu rename does not change existing configuration or API paths; `/api/storage/*` and `/api/webdav/*` stay the same.
