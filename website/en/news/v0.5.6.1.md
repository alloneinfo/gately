# Gately v0.5.6.1 released

October 22, 2026

This is a fix release for v0.5.6 that only affects the Docker image. Docker users should upgrade.

[Download v0.5.6.1](/en/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.6.1)

## Older nft on the host no longer crashes

The v0.5.6 Docker image ships nftables 1.1.5. Since 1.1.2, nftables writes set metadata that older versions do not understand, so an nft older than 1.1.1 on the host (such as 1.0.6 on Debian 12 and fnOS) crashes on `nft list ruleset`. Gately itself reads and writes its rules fine.

This release pins the image's nftables to 1.1.1. After upgrading, Gately rebuilds the `inet gately` table on start and the host's nft works again. The fnOS and OpenWrt packages and binary installs use the system's own nft and are not affected.

## Upgrade notes

- Docker: pull the new image and recreate the container. Other installs are the same as v0.5.6 and do not need to upgrade.
