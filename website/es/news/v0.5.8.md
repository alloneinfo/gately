# Gately v0.5.8 publicado

25 de octubre de 2026

Esta versión permite que Gately actúe como proveedor de identidad OIDC, añade el uso compartido de archivos por SMB ([#15](https://github.com/wangwanjie/gately/issues/15)), añade filtros a todos los registros ([#16](https://github.com/wangwanjie/gately/issues/16)) y permite cambiar el orden de los grupos de reglas del WAF ([#17](https://github.com/wangwanjie/gately/issues/17)).

[Descargar v0.5.8](/es/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.8) · [Documentación de inicio de sesión único OIDC](/es/docs/modules/oidc)

## Inicio de sesión único OIDC

Servicios web incluye un proveedor de identidad OpenID Connect. Gitea, OpenList, Grafana y otras aplicaciones compatibles con el inicio de sesión OIDC pueden iniciar sesión directamente con los usuarios compartidos y saber quién ha entrado, lo que sustituye la función OIDC de Authelia.

- Basta con indicar la URL del emisor y añadir clientes en «Servicios web → Ajustes globales → Proveedor de identidad OIDC»; el dominio del emisor no necesita un sitio;
- Los usuarios compartidos ganan correo, nombre visible y grupos opcionales, que se entregan a las aplicaciones como claims `email`, `name` y `groups`, para que puedan crear cuentas automáticamente y conceder permisos de administrador por grupo;
- Cada cliente puede limitarse a ciertos usuarios o grupos; se admiten PKCE, tokens de actualización y `prompt=none` / `prompt=login`, y los clientes públicos (aplicaciones de una sola página, apps móviles) deben usar PKCE;
- El inicio de sesión reutiliza la página de inicio de sesión de la autenticación web y la verificación en dos pasos TOTP; cuando el emisor está dentro del dominio de SSO, quien ya ha iniciado sesión en cualquier sitio entra en las aplicaciones sin volver a iniciar sesión;
- Cambiar la contraseña o el TOTP, eliminar el usuario o quitarlo de la lista de permitidos invalida al instante los tokens ya emitidos; `sub` es el ID fijo del usuario compartido y se mantiene al cambiarle el nombre;
- La documentación incluye ejemplos de configuración para Gitea, OpenList y Grafana, todos comprobados con la aplicación real.

## Servicio SMB

Servicios de archivos incorpora Servicio SMB, que comparte directorios locales con el Explorador de Windows, el Finder de macOS, Linux y los clientes SMB de móviles y televisores:

- SMB 2.0.2 a 3.1.1, autenticación y firma NTLMv2, con cifrado SMB 3 obligatorio opcional;
- Los usuarios se configuran igual que en FTP y WebDAV; cada usuario solo ve sus propios recursos compartidos y cada directorio puede ser de solo lectura;
- La página muestra la dirección de conexión de cada recurso compartido, y el anuncio por Bonjour permite que el Finder descubra el servicio directamente;
- Solo disponible en Linux y macOS. Windows solo se conecta al puerto 445, así que si el Samba que trae el NAS ya lo ocupa, elige otro puerto.

## Filtrado de registros

Registros del sistema y la tarjeta de registros de cada módulo se pueden filtrar por nivel, origen, palabra clave (con frases y palabras excluidas), IP o rango del cliente e intervalo de tiempo; Servicios web también filtra por sitio, dominio y código de estado. El filtrado se hace en el servidor, y «Cargar registros anteriores» sigue buscando en los archivos de registro guardados en disco. Los registros de acceso de Servicios web y los registros de coincidencias del WAF guardan la IP del cliente, el dominio, el código de estado y el ID de regla; al hacer clic en una etiqueta de un registro se filtra por ese valor. La API de registros acepta los mismos parámetros de filtro.

## Servicios web y WAF

- Las cabeceras de petición y de respuesta de los sitios se editan fila a fila, con nombres y valores que se eligen entre entradas comunes (HSTS, CSP, X-Frame-Options y otras); un clic añade las cabeceras de seguridad comunes, y el formato y los errores habituales se comprueban mientras escribes; el Content-Type de los sitios de texto fijo se elige entre los tipos comunes;
- Las cabeceras de petición cuyo nombre o valor contiene caracteres no válidos se rechazan al guardar; antes, una configuración así hacía que todo el sitio devolviera 502;
- Junto a las Opciones del proxy inverso hay una nueva explicación de qué hace cada una de las seis opciones y cuándo usarla;
- Los grupos de reglas del WAF se pueden subir y bajar. Las reglas de permiso (`allow`, `ctl:` y similares) van por encima de OWASP CRS, y las directivas de eliminación como `SecRuleRemoveById` van por debajo de CRS; la interfaz y la documentación lo explican.

## Correcciones

- Al cambiar el nombre de un usuario de FTP o WebDAV sin volver a escribir la contraseña, el guardado fallaba.

## Notas de actualización

- Cómo actualizar: las instalaciones con binario de Linux se actualizan desde la página Acerca de; en Docker descarga la nueva imagen y recrea el contenedor; en fnOS instala el nuevo `.fpk` desde el centro de aplicaciones; en OpenWrt instala el nuevo `.ipk` / `.apk`.
- El formato de configuración es compatible con versiones anteriores, así que puedes actualizar directamente. Los usuarios compartidos reciben un ID fijo en el primer arranque, que se escribe en el archivo de configuración.
- El formulario de inicio de sesión de la autenticación web rechaza los envíos desde otros sitios web; el inicio de sesión normal funciona igual.
