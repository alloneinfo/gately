# Gately v0.5.6.2 publicado

23 de octubre de 2026

Es una versión de corrección de la serie v0.5.6. Recomendamos actualizar todas las instalaciones.

[Descargar v0.5.6.2](/es/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.6.2)

## Docker 29 funciona en el módulo Docker

Desde Docker 25 sube la versión mínima de API admitida y Docker 29 exige al menos 1.44. Gately usaba siempre 1.41, por lo que la página de Docker indicaba que no podía conectarse. Ahora Gately lee el rango admitido en la primera conexión: mantiene 1.41 si el daemon lo admite, usa la mínima del daemon si no, y en motores anteriores a 20.10 usa la versión del propio motor.

## Sin sesión se va directo al inicio de sesión

La sesión se guarda en una cookie que la página no puede leer, así que sin sesión la interfaz mostraba el resumen hasta que una llamada a la API devolvía 401 y redirigía. Ahora se comprueba la sesión antes de mostrar una página: sin sesión aparece directamente el inicio de sesión y después se vuelve a la página solicitada.

## Cloudflare acepta configuraciones importadas de Lucky

Lucky solo usa el token de API de Cloudflare y las configuraciones importadas suelen conservar en el campo ID la AccessKey de otro proveedor. Gately la tomaba por el correo de la cuenta y usaba la Global API Key, por lo que DDNS y la validación de certificados fallaban con 6003 Invalid request headers. Ahora la Global API Key solo se usa cuando el ID es un correo; en los demás casos se usa el token.

## Los registros DDNS renombrados se sincronizan enseguida

Al editar una tarea, los registros con dominio, tipo, línea o TTL cambiados conservaban el estado anterior y se daban por sincronizados, así que el nuevo registro DNS nunca se creaba. Ahora se vuelven a sincronizar al guardar.

## Nuevo diseño de las páginas de inicio de sesión y de error del servicio web

La página de inicio de sesión de los sitios con autenticación web, las páginas de error 404 y 502 y la página que aparece al usar una entrada de seguridad incorrecta en la consola comparten ahora un diseño de tarjeta que sigue el tema claro u oscuro del sistema. La verificación en dos pasos pasa a una ventana emergente: tras aceptar el usuario y la contraseña se abre un cuadro para el código en la misma página, que se envía solo al completar 6 dígitos. Antes el usuario y la contraseña se borraban cuando hacía falta el código; ahora no hay que volver a escribirlos, y una contraseña incorrecta conserva el usuario. Las peticiones que no vienen de un navegador, como la CLI o la API, siguen recibiendo texto plano.

## Notas de actualización

- Docker: descarga la nueva imagen y recrea el contenedor. Las demás instalaciones pueden actualizarse en línea desde Ajustes o instalando el nuevo paquete.
- No hace falta revertir las tareas cuyo ID de Cloudflare vaciaste a mano por el error 6003.
