# Gately v0.5.5.1 출시

2026년 10월 21일

이번 버전은 [issue #8](https://github.com/wangwanjie/gately/issues/8)을 해결합니다. 지금까지 각 모듈의 실행 로그는 메모리에만 보관되어 컨테이너를 재시작하거나 업그레이드하면 사라졌습니다.

[v0.5.5.1 다운로드](/ko/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.5.1)

## 실행 로그 영구 저장

- 시스템 로그와 각 모듈 로그는 기본적으로 설정 디렉터리의 `logs/`에 출처별 JSON Lines 파일로 기록되므로, 재시작하거나 업그레이드한 뒤에도 「시스템 로그」와 각 모듈 페이지에서 이전 로그를 볼 수 있습니다.
- 새 로그는 최대 1초 늦게 묶어서 기록하며, 유휴 상태에서는 아무것도 쓰지 않습니다. 파일당 기본 상한은 2 MB이며, 가득 차면 교체하고 이전 파일 하나를 보관합니다.
- 「설정 → 네트워크 및 실행 → 실행 매개변수」에 「로그 영구 저장」 스위치와 「로그 파일 상한」이 추가되었고 즉시 적용됩니다. 끄면 이전처럼 메모리에만 보관합니다.
- 화면에서 모듈 로그를 지우면 해당 파일도 함께 삭제됩니다. 설정 백업에는 로그가 포함되지 않습니다.

작업 감사 로그는 원래부터 `audit.log`에 저장되며 바뀐 것은 없습니다. 자세한 내용은 [설정과 실행 매개변수 · 실행 로그](/ko/docs/guide/configuration#실행-로그)를 참고하세요.

## 업그레이드 안내

- v0.5.5에서 업그레이드: Linux 바이너리는 「정보」 페이지에서 바로 업그레이드하고, Docker는 새 이미지를 받아 컨테이너를 다시 만들고, fnOS는 앱 센터에서 새 `.fpk`를, OpenWrt는 새 `.ipk` / `.apk`를 설치합니다.
- v0.5.4 이하의 「업데이트 확인」은 세 자리 버전 번호만 인식하므로 v0.5.5.1을 표시하지 않습니다. 「정보」 페이지의 「업그레이드 패키지 업로드」로 Release에서 해당 플랫폼의 `.tar.gz`를 설치하거나, 먼저 v0.5.5로 업그레이드하세요.
- Docker에서는 로그가 마운트한 설정 디렉터리(예: `./gately-data/logs/`)에 있습니다.
