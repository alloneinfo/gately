# 변경 내역

주요 버전의 릴리스 공지는 아래와 같습니다. 모든 버전의 전체 변경 사항과 다운로드 파일은 [GitHub Releases](https://github.com/wangwanjie/gately/releases)에서 확인하세요.

## [v0.5.6.3](/ko/news/v0.5.6.3)

2026년 10월 23일 · OpenWrt에서 개요에 br-lan 인터페이스가 보이지 않던 문제와, 시간대를 설정할 수 없고 시간이 UTC로 계산되던 문제를 수정했습니다.

## [v0.5.6.2](/ko/news/v0.5.6.2)

2026년 10월 23일 · Web 서비스 로그인 화면과 오류 페이지를 새로 디자인하고 2단계 인증을 팝업으로 변경했습니다. Docker 29에서 Docker 모듈이 연결되지 않던 문제, 로그인 전에 개요 화면이 잠깐 보이던 문제, Lucky에서 가져온 Cloudflare 자격 증명과 이름을 바꾼 DDNS 레코드가 동기화되지 않던 문제를 수정했습니다.

## [v0.5.6.1](/ko/news/v0.5.6.1)

2026년 10월 22일 · Docker 이미지가 기록한 방화벽 규칙 때문에 호스트의 구버전 nft가 충돌하던 문제를 수정했습니다.

## [v0.5.6](/ko/news/v0.5.6)

2026년 10월 22일 · 침입 방지 추가: fail2ban 방식 로그 규칙, 미끼 포트, 포트 스캔 탐지와 nftables 차단 동기화.

## [v0.5.5.2](/ko/news/v0.5.5.2)

2026년 10월 22일 · fnOS 등의 파일 시스템에서 설정 디렉터리의 민감한 파일을 같은 기기의 다른 사용자가 읽을 수 있던 문제를 수정했습니다.

## [v0.5.5.1](/ko/news/v0.5.5.1)

2026년 10월 21일 · 실행 로그를 디스크에 기록해 재시작과 업그레이드 후에도 볼 수 있습니다.

## [v0.5.5](/ko/news/v0.5.5)

2026년 10월 21일 · nginx 설정 가져오기, 다른 호스트와 컨테이너로 인증서 자동 배포, WAF의 대용량 업로드와 WebDAV 지원, 구독 IP 목록이 추가되었고, 자가 점검에 인증서 적용 여부와 frp 충돌 검사가 추가되었습니다.

## [v0.5.4](/ko/news/v0.5.4)

2026년 10월 21일 · Linux 바이너리 설치의 온라인 업그레이드로 PVE LXC 컨테이너를 다시 만들 필요가 없어졌습니다. OpenWrt 패키지(.ipk / .apk)가 추가되었습니다.

## [v0.5.3](/ko/news/v0.5.3)

2026년 10월 21일 · fnOS 통합 게이트웨이에 연결되고 fnOS 관리자의 로그인 상태로 바로 로그인하는 fnOS 네이티브 앱. 기능 모듈을 필요에 따라 켜고 끌 수 있습니다.

## [v0.5.2](/ko/news/v0.5.2)

2026년 10월 20일 · SNI 라우팅으로 여러 서비스가 443 포트를 함께 쓰고, 웹 서비스가 nginx를 대체하며, 공유 사용자가 TOTP와 통합 로그인을 지원합니다. haproxy + nginx와의 성능 비교도 함께 실었습니다.

## [v0.5.0](/ko/news/v0.5.0)

2026년 10월 19일 · 감사 로그, 설정 기록과 되돌리기, 패스키, 읽기 전용 계정, ACME HTTP-01, HTTP/3, PROXY 프로토콜, 전역 Prometheus 지표, 네트워크 자가 점검, 서명된 릴리스.
