# Gately v0.5.6.1 출시

2026년 10월 22일

v0.5.6의 수정 버전으로 Docker 이미지에만 해당합니다. Docker 사용자는 업그레이드하세요.

[v0.5.6.1 다운로드](/ko/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.6.1)

## 호스트 nft 충돌 수정

v0.5.6 Docker 이미지에는 nftables 1.1.5가 들어 있었습니다. nftables 1.1.2부터는 구버전이 이해하지 못하는 메타데이터를 집합에 기록하므로, 호스트의 1.1.1 이전 nft(Debian 12, fnOS의 1.0.6 등)에서 `nft list ruleset`을 실행하면 충돌합니다. Gately 자체의 규칙 읽기와 쓰기에는 영향이 없습니다.

이번 버전은 이미지의 nftables를 1.1.1로 고정했습니다. 업그레이드하면 Gately가 시작할 때 `inet gately` 테이블을 다시 만들어 호스트의 nft도 정상으로 돌아옵니다. fnOS 패키지, OpenWrt 패키지, 바이너리 배포는 시스템의 nft를 쓰므로 영향이 없습니다.

## 업그레이드 안내

- Docker는 새 이미지를 받아 컨테이너를 다시 만들면 됩니다. 다른 배포 방식은 v0.5.6과 같아 업그레이드하지 않아도 됩니다.
