# Gately v0.5.5.2 출시

2026년 10월 22일

보안 수정 버전입니다. fnOS 사용자는 빨리 업그레이드하시기 바랍니다.

[v0.5.5.2 다운로드](/ko/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.5.2)

## 설정 디렉터리의 파일 권한 수정

일부 파일 시스템은 프로그램이 파일을 만들 때 지정한 권한을 무시합니다. 예를 들어 `trimacl`로 마운트된 fnOS 저장소 볼륨에서는 새 파일과 디렉터리가 모두 `0755`가 됩니다. 그래서 이런 볼륨에서 Gately가 만든 다음 내용은 같은 기기의 다른 사용자가 읽을 수 있었습니다.

- 실행 로그(`logs/`)와 작업 감사 로그(`audit.log`). 방문자 IP와 도메인이 들어 있습니다.
- 설정 기록(`history/`). 이전 버전의 규칙과 자격 증명이 들어 있습니다.
- frp 모듈이 생성한 설정(`frp/`). frp 토큰이 들어 있습니다.
- 구독 IP 목록 캐시, 로컬 백업, 복원 전에 자동 저장되는 백업, Tailscale 상태 디렉터리.

각 모듈의 설정 파일(`*.json`)은 원래부터 `0600`으로 저장되어 영향이 없습니다. ext4 같은 일반 파일 시스템도 영향이 없습니다.

이번 버전은 파일과 디렉터리를 만든 뒤 권한을 명시적으로 설정하고, 시작할 때 설정 디렉터리에 있는 위 내용을 파일은 `0600`, 디렉터리는 `0700`으로 제한하며 바꾼 개수를 시스템 로그에 기록합니다. `bin/`에 둔 프로그램과 설정 디렉터리 자체는 그대로 둡니다.

## 업그레이드 안내

- v0.5.5부터 Linux 바이너리는 「정보」 페이지에서 바로 업그레이드하고, Docker는 새 이미지를 받아 컨테이너를 다시 만들고, fnOS는 앱 센터에서 새 `.fpk`를, OpenWrt는 새 `.ipk` / `.apk`를 설치합니다.
- v0.5.4 이하의 「업데이트 확인」은 네 자리 버전 번호를 인식하지 못합니다. 「정보」 페이지의 「업그레이드 패키지 업로드」로 설치하거나, 먼저 v0.5.5로 업그레이드하세요.
- 설정 디렉터리의 파일을 다른 곳(예: NAS 공유 폴더 백업)에 복사한 적이 있다면 그 사본의 권한을 직접 확인하세요.
