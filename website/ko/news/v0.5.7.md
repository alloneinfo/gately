# Gately v0.5.7 출시

2026년 10월 24일

이번 버전은 스토리지 마운트에 SMB 공유를 추가하고([#14](https://github.com/wangwanjie/gately/issues/14)), 테마를 새로 설계했으며, 느린 회선이나 탭을 많이 연 상태에서도 관리 화면이 가볍게 동작하도록 했습니다.

[v0.5.7 다운로드](/ko/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.5.7) · [파일 서비스 문서](/ko/docs/modules/tools)

## SMB 공유 마운트

- 마운트 주소를 `smb://호스트[:포트]/공유이름[/하위디렉터리]` 형식으로 쓰면 Windows 공유, NAS, Samba 서버에 SMB2/3로 연결합니다;
- 사용자 이름, 비밀번호와 선택 사항인 도메인 또는 작업 그룹을 지정할 수 있으며, 사용자 이름이 비어 있으면 게스트로 연결합니다;
- 로컬 디렉터리, WebDAV 마운트와 마찬가지로 온라인 파일 관리와 예약 백업 대상에 사용할 수 있습니다;
- 연결은 처음 사용할 때 열리고, 서버가 연결을 끊으면 다음 작업에서 다시 연결합니다. 자격 증명이 틀리거나 공유가 없으면 명확한 오류를 보여 줍니다.

## 메뉴 이름 변경

사이드바의 "네트워크 스토리지"는 "파일 서비스"가 되었습니다. "스토리지 관리"는 "스토리지 마운트"(Gately가 로컬 디렉터리, 원격 WebDAV 또는 SMB 공유에 연결)로, "WebDAV"는 "WebDAV 서비스"(Gately가 로컬 디렉터리를 공유하며 "FTP 서비스"와 나란히 위치)로 바뀝니다. 개요, 가져오기 보고서, API 토큰 권한, API 문서의 모듈 이름도 새 이름을 따릅니다.

## 테마

- 15개 팔레트를 두 그룹으로 나눴습니다. Gately 오리지널(에메랄드, 오션, 프레시, 벚꽃, 노을, 미드나이트, 펑크)과 클래식 팔레트(GitHub, Nord, Dracula, Catppuccin, Tokyo Night, Gruvbox, Rosé Pine, Solarized)입니다. 모든 팔레트에 라이트와 다크가 있어 "시스템" 모드를 모든 팔레트에서 쓸 수 있습니다;
- 어떤 팔레트든 10가지 프리셋 강조색 중 하나를 고르거나 색상 선택기로 직접 고를 수 있고, 로고와 로그인 화면 그라데이션도 함께 바뀝니다. 모서리는 각진, 팔레트, 둥근 중에서 고를 수 있습니다;
- 테마 패널은 마우스를 올리면 미리 보기를 보여 주고, 전환할 때 원형으로 퍼지는 효과가 나타납니다;
- Web 터미널에 "UI 테마 따르기" 색 구성을 추가해 기본값으로 쓰며, Docker 컨테이너 터미널도 같은 설정을 사용합니다;
- 모든 팔레트에서 텍스트, 보조 텍스트, 강조색, 버튼이 대비 검사를 통과합니다.

이전 버전에서 선택한 테마는 처음 페이지를 열 때 자동으로 옮겨집니다. 기존 "다크" 테마는 에메랄드의 다크 버전이 됩니다.

## 더 빠르고 가볍게

- 관리 화면의 API 응답과 첫 페이지를 br 또는 gzip으로 보내고, 스크립트와 스타일은 빌드할 때 미리 압축합니다. 250 KB의 API 설명은 약 15 KB, 850 KB의 메인 스크립트는 약 270 KB로 전송됩니다;
- 프로그램이 약 11% 작아져 Linux amd64에서 약 32 MB입니다;
- 탭이 백그라운드에 있는 동안 15개 페이지와 패널의 주기적 새로 고침을 멈추고, 다시 보이면 즉시 새로 고칩니다. 이전 요청이 아직 진행 중이면 그 회차를 건너뜁니다;
- 로그 카드는 처음에 최신 200건만 가져오고, 이전 로그는 "이전 로그 불러오기"로 페이지 단위로 추가합니다. 로그 API에 `limit`와 `before` 매개변수가 추가되었습니다;
- 동적 DNS 페이지는 한 번의 왕복으로 로드됩니다.

## 수정

- 압축을 켠 Web 서비스 사이트: 브라우저가 gzip만 제공하는 일반 HTTP 접속에서, 업스트림이 이미 gzip으로 압축한 응답을 다시 압축해 브라우저에서 깨져 보였습니다;
- 침입 방지: 설정을 저장하거나 모듈을 다시 시작하면 버린 패킷 수, 미끼 포트와 스캔 탐지 적중 수가 0으로 초기화되었습니다;
- 언어 메뉴, 테마 패널, 사용자 메뉴가 열려 있을 때 마우스 휠과 터치로 아래 페이지가 스크롤되었습니다;
- 온라인 업그레이드가 실패한 직후 다시 시도하면 가끔 "업그레이드가 진행 중입니다. 잠시 기다려 주세요"가 표시되었습니다.

## 업그레이드 안내

- 업그레이드 방법: Linux 바이너리는 「정보」 페이지에서 바로 업그레이드하고, Docker는 새 이미지를 받아 컨테이너를 다시 만들고, fnOS는 앱 센터에서 새 `.fpk`를, OpenWrt는 새 `.ipk` / `.apk`를 설치합니다.
- 설정 형식은 그대로이므로 바로 업그레이드할 수 있습니다. 테마 선택은 브라우저에 저장되며, 각 브라우저에서 처음 페이지를 열 때 옮겨집니다.
- 메뉴 이름 변경은 기존 설정과 API 경로에 영향을 주지 않으며, `/api/storage/*`와 `/api/webdav/*`는 그대로입니다.
