# Lucky와 비교

Gately는 Lucky에서 영감을 받아 자주 쓰는 기능을 오픈소스로 구현했으며 기존 설정을 가져올 수 있습니다. 기능 폭과 사용자 기반 모두 Lucky가 앞서 있으며, Lucky가 없었다면 Gately도 없었을 것입니다. 이 자리를 빌려 감사드립니다.

## 철학의 차이

| 항목 | Gately | Lucky |
| --- | --- | --- |
| 소스 코드 | 오픈소스 (Apache-2.0) | 비공개 소스 |
| 설정 파일 | 일반 JSON, git으로 관리 가능 | 독자 포맷 (`.lkcf`) |
| 공식 서비스 | 기본값 없음, 모든 외부 주소를 수정하고 끌 수 있음 | 온라인 업데이트, 서드파티 로그인 중계 등 공식 서비스 제공 |
| 서드파티 로그인 | 직접 등록한 OAuth 앱 사용 | 공식 중계 서비스 경유 |
| 업그레이드 방식 | Docker / 패키지 관리자 | 내장 온라인 자체 업데이트 |
| 기능 범위 | 주요 핵심 기능 제공 | 더 풍부함 (DLNA, 클라우드 드라이브 마운트 등) |

## 의도적인 차이

- 바이너리를 덮어쓰는 온라인 자체 업데이트를 내장하지 않으며 업그레이드는 패키지 관리자나 Docker가 맡습니다.
- 원격 설정을 내려보내지 않고 기기 정보도 보고하지 않습니다.
- 설정은 일반 텍스트로 저장되며 민감한 필드는 API 출력에서 마스킹됩니다.
