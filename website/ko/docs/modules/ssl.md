# SSL 인증서

인증서를 자동으로 발급받고 갱신하여 [웹 서비스](/ko/docs/modules/web)에서 사용하며 다른 소프트웨어에도 내보낼 수 있습니다.

## 기능

- **ACME DNS-01** 자동 발급과 갱신: [동적 DNS](/ko/docs/modules/ddns)의 DNS 제공자를 재사용하므로 80 / 443 포트를 열 필요가 없습니다.
- 와일드카드 인증서와 EAB(예: ZeroSSL)
- 기존 인증서 업로드 또는 파일에서 읽기
- 디렉터리 매핑: 인증서가 바뀌면 지정한 디렉터리에 기록하고 스크립트를 실행하여 다른 서비스가 다시 로드하게 합니다.

## 인증서 매핑

인증서를 활성화하면 Gately가 `.crt`, `.key`, `.pem`, `_issuerCertificate.crt`를 매핑 디렉터리에 기록하고 변경 스크립트를 실행합니다. 파일 이름은 Lucky와 같고 기록되는 내용도 Lucky와 바이트 단위로 같습니다.

## 보안 안내

개인 키는 설정 디렉터리의 `ssl.json`에 저장됩니다. 이 파일을 안전하게 보관하고, 버전 저장소에 넣을 때는 저장소가 비공개인지 확인하세요.

## Lucky에서 마이그레이션

이미 발급된 인증서는 그대로 가져올 수 있으며 만료 전에는 다시 신청하지 않습니다. ZeroSSL은 Lucky의 EAB 자격 증명으로 새 ACME 계정을 등록합니다. 자세한 내용은 [마이그레이션 가이드](/ko/docs/guide/migration)를 참고하세요.
